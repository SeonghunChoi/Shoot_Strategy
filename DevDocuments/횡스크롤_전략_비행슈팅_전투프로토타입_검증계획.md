## 1. 목적과 위치

### 1.1 검증 순서

| 순서 | 대상 | 이유 |
|---|---|---|
| **1차 (본 문서)** | 횡스크롤 전투의 조작감 | 게임을 쌓아가는 데 가장 중요한 요소는 재미. 가장 먼저, 가장 싸게 확인 |
| 2차 | 전략 경제·다중 출격 턴 루프 | 자동 정산만으로 검증 가능 (전투 완성 불필요) |
| 3차 | 블렌더 툰 스타일 기체 제작 품질·속도 | 개인 리스크는 가장 크지만 1·2차와 병행 학습 가능 |

### 1.2 프로토타입의 성격

- **버리는 코드**다. 기술 설계 문서의 어셈블리 구조, DI, 데이터 파이프라인을 따르지 않는다
- 질문에 답하는 것 외의 완성도는 추구하지 않는다
- 아트는 기본 도형(큐브·캡슐·평면)만 사용
- 시작 전에 타임박스를 정한다. 기간이 끝나면 결과가 애매해도 판단을 내리고 종료한다

## 3. 조작 명세

### 3.1 씬 구조

```
Camera (또는 ScrollY)          플레이어 세로 이동을 따라 세로로만 이동
└─ ScrollX                     플레이어 가로 입력에 대응해 가로로만 이동
   ├─ Chunks (지형·충돌체)
   ├─ Enemy Spawners / Trajectories
   └─ Ground Targets
Player                         화면 가로 위치 고정, 세로로만 이동
Background (Loop)              가로: ScrollX 속도에 비례해 루프 스크롤 속도만 조절
                               세로: 카메라 이동에 비례해 이동
```

- 청크·적 궤적을 ScrollX에 붙이므로 플레이어와 적의 상대 운동은 기존 횡스크롤과 동일. 달라지는 것은 시각 표현(카메라가 플레이어 가로 위치에 고정)뿐
- ScrollY를 둘지 카메라 이동만으로 처리할지는 구현 편의로 결정

### 3.2 가로 입력 — 두 모드 (토글)

| 모드 | 동작 |
|---|---|
| A. 위치 오프셋 | 기본 스크롤은 일정. 입력은 기준 위치에서 ScrollX를 앞뒤로 밀어내는 오프셋. 오프셋은 기존 화면 폭 상당 범위로 제한. 입력을 떼면 그 자리 유지. 스테이지 길이 거의 일정 |
| B. 속도 조절 | 입력이 스크롤 속도를 가감. 최저·최고 속도 사이, 관성 있음. 누적 이동량이 진행 거리 → 플레이어가 진행 시간을 조절 가능 |
| B 옵션: 순항 복귀 | 입력을 떼면 순항 속도로 서서히 복귀 (스로틀 유지 피로감 비교용) |

기본 목표는 모드 A. 모드 B는 전략적 활용 가능성 확인용.

### 3.3 세로 입력과 카메라

- 기체가 직접 상하 이동, 카메라가 세로로 추적
- 맵 높이는 화면보다 큼
- 레이더 HUD: 화면 밖(위·아래) 적 위치 표시

### 3.4 지형 충돌

- 고정 지형과 충돌 시 피해 + 튕겨남
- 피해량·튕김 강도는 조절 가능하게 (난이도별 차등 검토용)

### 3.5 선회 구역

- 맵 설정에서 지정한 구역에서만 동작. 고정형(또는 저속) 대형 보스를 한 번의 스크롤로 처리할 수 없을 때 사용
- 클리어 전에는 구역 양 끝에 도달하면 자동 선회 → 진행 방향 반전, 기체 화면 위치도 반대편으로
- 선회 중: 조작 불능, 일시 무적, 적 미등장, 스테이지 타이머·전경 시간 정지
- 구역 내 잡몹 웨이브 있음
- 선회 횟수 제한은 이번 범위 밖

### 3.6 기체 전환

- 편대 2~4기 (프로토타입은 3기 고정)
- 전환 시 짧은 무방비/슬로우
- 비조작 기체의 배경 레이어 연출은 이번 범위 밖 (단순 표시만)

## 4. 입력 배치

### 4.1 게임패드 — 비교 대상 2안

| 입력 | 배치 1 (기본) | 배치 2 (원안) |
|---|---|---|
| 왼쪽 스틱 | 상하 이동 + 가로 입력 | 상하 이동 + 가로 입력 |
| RT | 기관포 | 기관포 |
| LT | 하드포인트 무장 | 하드포인트 무장 |
| 기체 전환 | LB 탭: 다음 기체 / LB 홀드: 링 메뉴, 오른쪽 스틱 선택 | North 홀드: 링 메뉴 |
| 무장 종류 선택 | 방향키 좌우 | 방향키 좌우 |
| 임의 선회 (Q7 테스트) | RB | RB |

배치 2는 North와 링 선택 스틱이 모두 오른손 엄지라, 선택 중 왼쪽 스틱(비행)을 써야 하는지 확인이 필요하다. 이 부담의 체감이 비교 포인트.

### 4.2 키보드

| 입력 | 키 |
|---|---|
| 상하 이동 + 가로 입력 | 방향키 또는 WASD |
| 기관포 | J |
| 하드포인트 무장 | K |
| 기체 전환 | L 탭: 다음 기체 / L 홀드: 링 메뉴 (방향키로 선택) |
| 무장 종류 선택 | Q / E |
| 임의 선회 | I |

(키 배치는 초안. 프로토타입 중 자유롭게 변경)

## 5. 토글·조절 항목 (디버그 메뉴)

| 항목 | 값 |
|---|---|
| 가로 입력 모드 | A / B / B + 순항 복귀 |
| 모드 A 오프셋 범위 | 수치 |
| 모드 B 최저·순항·최고 속도, 가속도 | 수치 |
| 기본 스크롤 속도 | 수치 |
| 카메라 세로 추적 방식 | 즉시 / 부드럽게 / 데드존 |
| 기체 전환 무방비 시간 | 수치 (0 포함) |
| 링 메뉴 슬로모션 | on / off, 배율 |
| 입력 배치 | 배치 1 / 배치 2 |
| 임의 선회 | on / off |
| 지형 충돌 피해·튕김 강도 | 수치 |
| 레이더 HUD | on / off |

## 6. 테스트 콘텐츠 (최소)

| 요소 | 내용 |
|---|---|
| 스테이지 | 3~5분 분량 1개. 평지 구간 → 산악 구간(지형 충돌) → 선회 구역(고정 보스) |
| 맵 높이 | 화면 2~3배 |
| 기체 | 3종: 제공기(빠름·기관포 강함), 공격기(대지 무장), 폭격기(느림·대형 폭탄). 차이는 수치와 색상으로만 |
| 적 | 공중 잡몹 궤적 3종(직선·곡선·추적), 지상 목표 2종(대공포·고정 목표) |
| 보스 | 고정형 1기, 부위 2~3개 |
| 하드포인트 무장 | 미사일, 폭탄 2종 (방향키로 전환) |

## 7. 관찰과 기록

### 7.1 플레이테스트

- 본인 플레이 + 가능하면 횡스크롤 슈팅 경험자 / 비경험자 각 1명 이상
- 설명 없이 조작을 익히는 과정을 관찰 (Q1, Q8의 핵심)

### 7.2 수집 로그 (간단히)

| 지형 충돌 횟수·위치 | Q9 |

## 8. 종료 조건과 결과 반영

- 타임박스 종료 시점 또는 Q1~Q9에 판단이 모두 나오면 종료
- 판단 결과는 다음 문서에 반영:

| 결정 | 반영 위치 |
|---|---|
| 가로 입력 모드 (A/B) | 기획서 7.1 (현행 "강제 스크롤 + 가감속" 개정), 8장 시간 기반 규칙 검토 |
| 세로 카메라 추적·맵 높이 | 기획서 7.3, 기술 설계 6.1 |
| 전환 방식·무방비 시간·슬로모션 | 기획서 7.1, 11.3 |
| 입력 배치 (패드·키보드) | 기획서 11.4 |
| 선회 구역·임의 선회 | 기획서 7장 (선회 구역 규칙 신설) |
| 지형 충돌 | 기획서 7.1, 난이도 모디파이어 |
| 레이더 HUD | 기획서 11.3 |

- 프로토타입 코드는 폐기. 조절 항목의 최종 수치만 기록으로 남긴다
