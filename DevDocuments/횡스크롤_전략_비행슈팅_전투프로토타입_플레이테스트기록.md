## 2. 입력 배치 (검증계획 4.1 + 추가안)

| 입력 | 배치 1 (기본) | 배치 2 (원안) | 배치 3 (트리거 스로틀, 09-29 추가) |
|---|---|---|---|
| 왼쪽 스틱 | 상하 이동 + 가로 입력 | 상하 이동 + 가로 입력 | 상하 이동만 |
| 가로 입력 | 스틱 가로 | 스틱 가로 | RT 가속 / LT 감속 (아날로그) |
| 기관포 | RT | RT | South |
| 하드포인트 무장 | LT | LT | East |
| 무장 종류 선택 | 방향키 좌우 | 방향키 좌우 | West / North |
| 기체 전환 | LB 탭 / 홀드 링 (오른쪽 스틱) | North 홀드 링 | LB 탭 / 홀드 링 (오른쪽 스틱) |
| 임의 선회 | RB | RB | RB |

배치 3 추가 이유: 가로 입력을 버튼(트리거)으로 하면 "떼면 속도 유지"인 모드 B가 자연스럽다는 관찰 (Q2).

## 3. 세션 로그

### 2026-09-29 — 2단계 (이동·스크롤·카메라)

- 테스트 범위: 가로 모드 A / B / B+, 세로 이동, 카메라 "부드럽게"
- 사용 수치: 기본값 (기본 스크롤 8, 오프셋 ±16, B 속도 3 / 8 / 16, 가속 10, 순항 복귀 4, 세로 속도 10, 맵 높이 2.5배, 카메라 추적 0.2초)
- 관찰
  - 스틱 조절 → A 또는 B+가 어울림
  - 숄더·트리거 조절 → B가 어울림 → 배치 3 신설
  - 세로 이동·카메라 느낌은 현재가 원하는 방향에 가까움
- 다음에 확인할 것
  - 배치 3 + 모드 B 장시간 비행
  - 카메라 즉시·데드존 비교

### 2026-09-29 — 3단계 (무장과 적)

- 테스트 범위: 기관포, 유도 미사일, 폭탄, 공중 잡몹 3종, 대공포·고정 목표 (임시 자동 등장)
- 관찰
  - 모드 A에서 뒤로 입력하며 폭탄 투하 시 폭탄이 뒤로 떨어짐. 원인: 오프셋 이동 속도(12) > 기본 스크롤(8) → 대지 속도 −4 (후진). B/B+는 최저 속도 3이라 수직 또는 앞쪽 포물선
  - 적 탄이 A/B 모두 어색함. 원인: 적·지상 목표는 지면(ScrollX) 좌표, 적 탄만 화면 좌표 → 가감속 시 탄만 따로 노는 것처럼 보임
- 조치
  - 폭탄이 이어받는 대지 속도를 0 이상으로 제한 (모드 A의 뒤로 입력은 화면 내 위치 이동이지 후진이 아니라는 해석)
  - 적 탄을 지면 좌표로 이동, 공중 적 탄은 발사 기체 속도 계승, 기체 대지 속도 기반 예측 사격
  - 결과: 두 문제 모두 해소 확인
- 설계 메모 (본 구현 반영 후보)
  - 전투 내 모든 월드 오브젝트(적·지상 목표·적 탄·폭탄)는 지면 좌표계, 기체와 기관포 탄만 화면 좌표계로 두는 규칙이 자연스러움
  - 모드 A 채택 시 "뒤로 입력 = 후진 아님"을 물리 규칙에 명시해야 함 (폭탄 등 대지 속도 계승 대상)
- 추가 조정
  - 적 예측 사격 정확도 항목 추가 (0 = 현재 위치, 1 = 완전 예측)
  - B 모드 순항 속도를 기본 스크롤 속도로 통합

### 2026-09-29 — 4단계 (지형과 스테이지)

- 테스트 범위: 평지 700m → 산악 900m → 선회 구역 입구(종료), 지형 충돌, 레이더 가장자리 / 세로 띠
- 관찰
  - B/B+에서 기본 스크롤 속도를 30으로 올려도 속도가 3~16에 머묾. 원인: B 속도가 절대값(최저 3·최고 16)으로 잘림
- 조치
  - B 속도 = 기본 스크롤 + 스로틀, 스로틀 범위 = −감속 폭(5) ~ +가속 폭(8). HUD에 스로틀 표시
- 다음에 확인할 것
  - 산악 통로의 지형 충돌 긴장감 (Q9) — 피해·튕김 강도별 비교
  - 레이더 가장자리 vs 세로 띠 (Q3)
  - 카메라 즉시·데드존 비교 (2단계부터 이월)
