## 1. 질문별 기록 (검증계획 7.3)

| 질문 | 관찰 | 판단 | 반영할 결정 |
|---|---|---|---|
| Q1 가로 입력 = 속도감 변화가 직관적인가 | (09-29) 모드 A·B·B+ 모두 조작해 봄. 입력 수단에 따라 어울리는 모드가 다르다는 인상 (Q2 참조). 3단계에서 적·적 탄·폭탄을 모두 지면 좌표로 통일 → 가로 입력이 적 접근 속도·탄 회피·폭탄 낙하점에 영향 **(10-19 응답, 성훈 · 지인 테스터)** 둘 다 좌우 입력이 스크롤 속도(속도감)로 바로 느껴짐. 지인: 게임을 조금만 해본 사람이면 바로 이해, 답답함 없음 | **성립** | 가로 입력 = 스크롤 속도 조절 채택 (기획서 전투 조작) |
| Q2 모드 A vs B | (09-29) 스틱으로 조절 시 A / B+(순항 복귀)가 어울림. 숄더·트리거로 조절 시 B(떼면 속도 유지)가 어울림 → 트리거 스로틀 배치 3 추가. 4단계 중 B의 속도 범위를 "기본 스크롤 ± 폭"으로 변경 (기본 스크롤을 올리면 B도 함께 빨라지길 기대) **(10-19)** 둘 다 B. 지인: 앞 = 가속, 뒤 = 감속, 놓으면 속도 유지가 직관적. 지인 튜닝: B + 순항 복귀, 기본 20 / 감속 폭 5 / 가속 폭 8 / 가속도 10 / 복귀 4 | **B 채택** | B 속도 = 기본 스크롤 + 스로틀(−감속 폭~+가속 폭) 구조 유지 후보. B 속도 = 기본 스크롤 + 스로틀(−감속 폭 ~ +가속 폭). 순항 복귀는 옵션 |
| Q3 세로 맵 + 카메라 + 레이더로 적 파악 | (09-29) 세로 이동·카메라 "부드럽게"(추적 0.2초)가 원하는 느낌에 가까움. 즉시·데드존은 미비교. 4단계에서 레이더 2방식(가장자리 / 세로 띠) 구현, 동작 확인 **(10-19)** 성훈: 레이더가 화면 밖 적 파악에 도움, 그러나 횡스크롤 특성상 시선이 분산됨 → 더 알아보기 쉽게 또는 다른 방식. 지인: 레이더는 반드시 필요, 특히 세로 띠는 꼭. 정보가 없으면 답답, 있으면 짧게라도 움직임을 고민하게 됨. 지인 최대 답답 순간: 적 기체를 빨리 인지 못해 놓침 | **레이더 필요, 표현은 개선 필요** | 세로 띠 레이더를 기본으로. 시선 분산 줄이기: 화면 가장자리 진입 예고 화살표와 병행, 위협만 강조. 카메라 "부드럽게"(0.2초) 유지 |
| Q4 기체 전환 부담·무방비 시간 | (09-29) 5단계에서 탭·링 전환, 무방비(발사 불가 + 세로 이동 ×0.5, 기본 0.5초), 격추 시 자동 투입 구현, 동작 확인. 체감 판단은 미기록 **(10-19)** 둘 다 부담 없음. 지인: 무방비 시간이 불쾌하지 않음, 위험해도 교체 리스크로 당연하다고 느낌 | **성립** | 전환 무방비 0.5초 유지 |
| Q5 탭 순환만으로 충분한가 / 링 슬로모션 | (09-29) 링 메뉴(홀드 0.25초, 3칸) + 슬로모션(×0.3) 구현, 동작 확인. 탭 vs 링 비교는 미기록 **(10-19)** 성훈: 둘 다 좋음 — 링 = 원하는 기체로 즉시, 탭 = 급할 때. 슬로모션이 없었다면 불편했을 것. 지인: 처음엔 둘 다 좋다가 링 + 슬로 없음이 긴장감 있음, 결국 탭 위주로 플레이. 지인 튜닝: 링 슬로모션 끄기 | **탭 + 링 둘 다 유지. 슬로모션은 의견 갈림** | 탭·링 유지. 링 슬로모션은 옵션(기본 켜기, 배율 완화) 또는 난이도별 — 본 게임 조작 설정 항목으로 |
| Q6 선회 구역 고정형 보스전 | (09-29) 6단계에서 선회 구역 160m + 지상 요새 보스(포탑 2 → 코어) + 양 끝 자동 선회 구현, 동작 확인. 재미 판단은 미기록 **(10-19)** 둘 다 긍정. 성훈: 선회 후 레이더로 적 위치를 파악해 공격하는 재미. 지인: 지루하지 않고 타이밍 맞춰 폭탄 떨구는 집중 계기, 선회 시간은 1~2초 더 짧게 (지인 튜닝 1.2초) | **성립** | 선회 구역 보스전 채택. 선회 시간 1.2초 전후 |
| Q7 임의 선회 | (09-29) 임의 선회(RB / I, 디버그 토글) 구현, 동작 확인. 판단은 미기록 **(10-19)** 지인: 임의 선회가 더 재미, 원하는 타이밍에 원하는 그림의 공격 가능. 선회 콘텐츠로 게임 성격을 지킬 수 있음. 성훈: 나쁘지 않으나 스테이지 성격에 따라 허용 | **임의 선회 긍정, 범위는 스테이지 단위** | 임의 선회 허용 여부를 스테이지(청크) 속성으로 — 선회 구역·보스전에서 허용, 일반 진행 구간은 자동 선회만 |
| Q8 입력 배치 진입장벽 | (09-29) 배치 3(트리거 스로틀) 신설 — 배치 1·2와 함께 비교 대상 **(10-19)** 성훈(Xbox 패드): 배치 3이 가장 편함. 지인(키보드만): 할 만함, 버튼을 모를 때 답답했으나 알고 나서는 괜찮음 | **성립 (패드 배치 3, 키보드 가능)** | 패드 기본 = 배치 3(트리거 스로틀). 첫 출격에 버튼 안내(화면 표시·튜토리얼) 필수 |
| Q9 지형 충돌 긴장감 | (09-29) 4단계에서 산악 구간 지형 충돌(피해 + 튕김 + 정면 넉백) 구현, 동작 확인. 긴장감 판단은 미기록 **(10-19)** 둘 다 긴장감 없음 (피해 10이 작아 무시하고 진행). 성훈: 고속에서 급경사는 피할 수 없음 — 피해를 키우면 레이더 등으로 지형 예고 필요. 최대 답답 순간도 고속 중 갑자기 나타난 급경사. 지인: 지형 충돌 = 사망이면 긴장감, 그러려면 레이더 범위 확대 | **현재 수치로는 긴장감 없음. 피해를 키우려면 예고가 전제** | 지형 충돌 피해 상향(즉사 또는 큰 피해)과 전방 지형 예고(레이더·경고 표시)를 한 묶음으로. 고속에서 반응 불가능한 급경사는 레벨 디자인 규칙으로 금지 |

## 2. 입력 배치 (검증계획 4.1 + 추가안)

| 입력 | 배치 1 (기본) | 배치 2 (원안) | 배치 3 (트리거 스로틀, 09-29 추가) |
|---|---|---|---|
| 왼쪽 스틱 | 상하 이동 + 가로 입력 | 상하 이동 + 가로 입력 | 상하 이동만 |
| 가로 입력 | 스틱 가로 | 스틱 가로 | RT 가속 / LT 감속 (아날로그) |
| 기관포 | RT | RT | South |
| 하드포인트 무장 | LT | LT | East |
| 무장 종류 선택 | 방향키 좌우 | 방향키 좌우 | West / North |
| 기체 전환 | LB 탭 / 홀드 링 (오른쪽 스틱) | North 홀드 링 | LB 탭 / 홀드 링 (오른쪽 스틱) |
| 임의 선회 | RB | RB | RB |

배치 3 추가 이유: 가로 입력을 버튼(트리거)으로 하면 "떼면 속도 유지"인 모드 B가 자연스럽다는 관찰 (Q2).

## 3. 세션 로그

### 2026-09-29 — 2단계 (이동·스크롤·카메라)

- 테스트 범위: 가로 모드 A / B / B+, 세로 이동, 카메라 "부드럽게"
- 사용 수치: 기본값 (기본 스크롤 8, 오프셋 ±16, B 속도 3 / 8 / 16, 가속 10, 순항 복귀 4, 세로 속도 10, 맵 높이 2.5배, 카메라 추적 0.2초)
- 관찰
  - 스틱 조절 → A 또는 B+가 어울림
  - 숄더·트리거 조절 → B가 어울림 → 배치 3 신설
  - 세로 이동·카메라 느낌은 현재가 원하는 방향에 가까움
- 다음에 확인할 것
  - 배치 3 + 모드 B 장시간 비행
  - 카메라 즉시·데드존 비교

### 2026-09-29 — 3단계 (무장과 적)

- 테스트 범위: 기관포, 유도 미사일, 폭탄, 공중 잡몹 3종, 대공포·고정 목표 (임시 자동 등장)
- 관찰
  - 모드 A에서 뒤로 입력하며 폭탄 투하 시 폭탄이 뒤로 떨어짐. 원인: 오프셋 이동 속도(12) > 기본 스크롤(8) → 대지 속도 −4 (후진). B/B+는 최저 속도 3이라 수직 또는 앞쪽 포물선
  - 적 탄이 A/B 모두 어색함. 원인: 적·지상 목표는 지면(ScrollX) 좌표, 적 탄만 화면 좌표 → 가감속 시 탄만 따로 노는 것처럼 보임
- 조치
  - 폭탄이 이어받는 대지 속도를 0 이상으로 제한 (모드 A의 뒤로 입력은 화면 내 위치 이동이지 후진이 아니라는 해석)
  - 적 탄을 지면 좌표로 이동, 공중 적 탄은 발사 기체 속도 계승, 기체 대지 속도 기반 예측 사격
  - 결과: 두 문제 모두 해소 확인
- 설계 메모 (본 구현 반영 후보)
  - 전투 내 모든 월드 오브젝트(적·지상 목표·적 탄·폭탄)는 지면 좌표계, 기체와 기관포 탄만 화면 좌표계로 두는 규칙이 자연스러움
  - 모드 A 채택 시 "뒤로 입력 = 후진 아님"을 물리 규칙에 명시해야 함 (폭탄 등 대지 속도 계승 대상)
- 추가 조정
  - 적 예측 사격 정확도 항목 추가 (0 = 현재 위치, 1 = 완전 예측)
  - B 모드 순항 속도를 기본 스크롤 속도로 통합

### 2026-09-29 — 4단계 (지형과 스테이지)

- 테스트 범위: 평지 700m → 산악 900m → 선회 구역 입구(종료), 지형 충돌, 레이더 가장자리 / 세로 띠
- 관찰
  - B/B+에서 기본 스크롤 속도를 30으로 올려도 속도가 3~16에 머묾. 원인: B 속도가 절대값(최저 3·최고 16)으로 잘림
- 조치
  - B 속도 = 기본 스크롤 + 스로틀, 스로틀 범위 = −감속 폭(5) ~ +가속 폭(8). HUD에 스로틀 표시
- 다음에 확인할 것
  - 산악 통로의 지형 충돌 긴장감 (Q9) — 피해·튕김 강도별 비교
  - 레이더 가장자리 vs 세로 띠 (Q3)
  - 카메라 즉시·데드존 비교 (2단계부터 이월)

### 2026-09-29 — 5단계 (기체 전환)

- 테스트 범위: 편대 3기, 탭 순환, 링 메뉴(패드 오른쪽 스틱 / 키보드 L + 방향키), 링 슬로모션, 교대 무방비, 격추 시 자동 투입, 전멸
- 계획 변경 (구현 전)
  - 기체별 가로 입력 배율 추가 요청 → 제공기 A 오프셋 이동 ×1.3·B 가속 폭 ×1.3, 폭격기 A ×0.7·B 감속 폭 ×0.8·가속 폭 ×0.6
  - 기체 선택이 스크롤 조작감에도 영향을 주게 됨 → 기체 역할 차이에 "기동성(가로 입력)"이 포함되는지는 본 설계 검토 대상
- 구현 결정
  - 무방비 = 발사 불가 + 세로 이동 감속, 피격 무적 없음
  - 기체별 체력·장탄은 출격 중 유지, 비전경 기체는 회복 없음
  - 전멸 시 테스트용 2초 복구 (끄면 결과 창)
- 결과: 동작 확인
- 다음에 확인할 것
  - 무방비 시간 0 / 0.5 / 1초 비교 (Q4)
  - 탭 vs 링 사용 비율, 슬로모션 on/off (Q5)
  - 배치 1·2·3·키보드별 전환 조작 부담 (Q8)
  - 기체별 가로 입력 차이 체감

### 2026-09-29 — 6단계 (선회 구역과 보스)

- 테스트 범위: 진행 방향 반전, 자동 선회(구역 양 끝), 임의 선회, 보스 부위 파괴·패턴 변화, 격파 후 스테이지 종료
- 구현 결정
  - 선회 = 속도가 0을 지나 반대로 (기본 1.2초), 기체는 위로 호를 그리며 화면 반대편으로. 조작 불능·무적·적 미등장·타이머/전경 시간 정지
  - 모드 A는 선회 시 오프셋을 접어 새 기준으로 (화면 튐 방지)
  - 보스 본체는 지형으로 처리 (충돌·탄 차단·폭탄 폭발 공용) → 본 구현에서도 "고정형 보스 본체 = 지형 청크" 방식 검토 가치
  - 선회 구역 300m → 160m (한 번 통과 약 20초)
- 저장된 튜닝 값 (09-29 시점, 테스트 중 선택한 조합)
  - 가로 입력 모드 B, 기본 스크롤 20, 감속 폭 5 / 가속 폭 8, 패드 배치 3 (트리거 스로틀), 레이더 둘 다
  - 참고: 이 시점에 씬의 튜닝 에셋 참조가 비어 있던 것이 복구됨 → 그 이전 세션의 디버그 조정값은 에셋에 저장되지 않았을 수 있음
- 결과: 동작 확인
- 다음에 확인할 것
  - 고정형 보스를 오가며 공략하는 재미 (Q6)
  - 임의 선회의 재미 vs 게임 성격 (Q7)
