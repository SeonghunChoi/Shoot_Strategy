## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 횡스크롤 비행 슈팅 + 턴제 헥스 전략 |
| 중심 | 직접 조작하는 횡스크롤 슈팅. 전략 맵은 출격의 맥락(어디서·무엇으로·왜 싸우는가)과 보상(성장·우세)을 만드는 보조 수단 |
| 모티브 | 슈퍼패미콤판 에어리어88 (보수로 기체·무장을 사서 싸우는 구조, 맵 위 작전 선택) |
| 플랫폼 | PC + 콘솔 (게임패드 기준 설계, PC 마우스 병행) |
| 무대 | 근미래 지구의 분쟁 지역 |
| 플레이어 | 한 세력에 소속된 비행 부대 지휘관 (직접 비행하지 않으며, 전투에서는 소속 파일럿의 기체를 조작) |
| 아트 | 3D 스타일라이즈, 횡스크롤 시점의 2.5D 전투 / 2D 탑다운 전략 맵 |
| 원작에서 계승하는 요소 | 자금 압박, 기체 구매·개조의 재미, 소모전의 긴장감 |

### 한 줄 소개

편대의 기체를 바꿔 타며 직접 전장을 돌파하는 횡스크롤 슈팅. 늘 돈이 모자란 전선 지휘관으로서 어디에 편대를 보낼지 정하고, 그 전과로 세력을 키워 적을 압도한다.

## 2. 핵심 설계 원칙

**슈팅이 중심이고, 전략은 출격의 맥락과 보상을 만든다.**
이 게임의 핵심 재미는 직접 비행하는 횡스크롤 슈팅이다. 전략 맵은 어디서·무엇으로·왜 싸우는가를 정하고, 싸운 결과를 성장과 우세로 돌려주는 보조 수단이다. 전략 규칙을 더하거나 바꿀 때는 "출격을 더 의미 있게 만드는가, 직접 플레이할 교전을 줄이지 않는가"로 판단한다.

**편대는 교체 가능한 기체 풀이다.**
화면에는 늘 1기만 싸운다. 어떤 기체를 묶어 보낼지가 전투의 전술이 된다.

**판단이 쌓여 세력이 커지고 적을 압도한다.**
전략 쪽의 목표는 나의 전략적 판단으로 아군의 위세가 강해져 적을 압도하는 것이다. 전략의 재미를 한 가지 요소로 정의하지 않는다. 아래 원칙들은 그 판단을 만드는 수단이다.

### 전략 판단의 수단

**얼마나 내보내고, 얼마나 남길 것인가.**
편대는 맵 위를 여러 턴 날아다니고, 하늘에 있는 편대는 거점을 지키지 못한다. 적은 여러 방향에서 동시에 온다. 매 턴의 질문은 "어디를 칠 것인가"이자 "어디를 비워둘 것인가"다.

**연료는 지휘관의 판단이다.**
귀환은 자동으로 일어나지 않는다. 연료가 바닥나 기체를 잃더라도 몰려오는 적을 막는 편이 낫다면 그렇게 할 수 있다. 초계·드롭탱크·공중 급유기, 레이더의 미확인 접촉(4장)이 그 판단의 폭을 넓힌다.

**방공망을 벗겨내야 본진이 열린다.**
적 거점 주변에는 호위 부대와 방공망이 붙어 있다. 여러 편대가 순서대로 벗겨내야 본진 폭격이 통한다.

**지휘관은 늘 돈이 모자란다.**
거점 유지비와 파일럿 급여라는 무거운 고정비가 매 턴 빠져나간다. 큰 수입은 빼앗길 수 있는 자원 타일에서 나온다.

**손실의 무게는 위치가 정한다.**
아군 영역 위에서 격추되면 잔해를 회수할 수 있지만, 적진 깊숙이 들어가면 기체는 영구 손실이고 파일럿은 포로가 될 수 있다.

**거점은 무엇을 키울지 고르는 곳이다.**
거점은 맵의 칸 하나이고, 시설 규모(시설 등급의 합)에 상한이 있다. 격납고·활주로·정비소·방공·유흥가가 같은 상한을 두고 경쟁한다.

**상부는 결과만 본다.**
상부 신뢰도는 전과가 아니라 명령 이행과 거점·자원 확보로만 오른다. 신뢰를 잃으면 해임된다.

## 3. 코어 루프

턴 내부의 정보 확인·운영·명령은 자유 순서로 진행하며, 출격은 생략할 수 있다.

| 단계 | 내용 |
|---|---|
| 정보 | 탐지 범위 내 적 부대 이동, 거점 위협, 상부 지시 확인 |
| 운영 | 거점 건설·확장·등급 상승, 시설 등급 상승, 기체 구매·개조, 편대 편성, 지상군 고용·강화 |
| 명령 | 지상군 출동 (목표 헥스 지정, 출동 비용 지불), 급유기 호출 |
| 편대 비행 (선택) | 편대마다 갈 칸 지정 → 이륙(첫 명령 때 비용) → 맵 위로 이동이 재생됨. 적 부대·거점 칸이면 교전, 아군 거점이면 착륙. 순서는 명령한 순서 |
| 교전 | 직접 플레이 또는 자동 정산 → 디브리핑. 앞 교전의 결과가 뒤 명령에 반영 |
| 정산 | 전과 보상, 기체 손상·손실, 파일럿 경험치·탈출·포로 처리 |
| 턴 종료 → 아군 AI | 지상군이 지정 목표로 이동·전투·점령. 하늘에서 턴을 마친 편대는 연료 소모(아군 영역 위 초계는 없음) |
| 적 턴 | 적 세력 이동·공격(이동이 맵 위에 재생됨), 세력 간 교전, 자원 타일 점령, 이동 중 아군 지상군·비행 편대·급유기 공격, 편대 주둔 거점의 자동 요격 |

### 출격 목적

- 적 부대 격파
- 적 거점 공격 / 점령 지원
- 아군 거점 방어
- 특수: 정찰, 호위, 보급선 차단, 구출

### 출격 규칙 — 다턴 비행

전략 프로토타입에서 세 방식(한 턴 왕복 / 체공 / 다턴 비행)을 비교해 다턴 비행을 채택했다. 편대가 맵 위에 있어 "내 편대를 조종한다"는 감각이 가장 강했다.

| 항목 | 규칙 (수치는 프로토타입 값) |
|---|---|
| 이륙 | 거점에 있는 편대에 갈 칸을 지정하면 이륙. 출격 비용(연료·탄약)은 이륙 때 한 번 |
| 이동 | 턴마다 속도만큼 직선으로 날아감 (소형 3, 중형 3~4). 한 칸마다 연료 1 |
| 연료 | 이륙 때 작전 반경 × 2 + 예비 1. 아군 영역 밖에서 턴을 마치면 연료 1 추가 소모 |
| 초계 | 아군 영역 위에서 턴을 마치면 연료를 쓰지 않는다 |
| 드롭탱크 | 거점에서 장착하면 연료 × 1.5. 탱크 분량부터 쓰고, 교전(어느 쪽이 걸든)하거나 공격 목표에 도착하면 버린다 |
| 공중 급유기 | 4장 비행 운용 참고 |
| 교전 | 적 부대·거점·적 자원 타일 칸에 도착하면 교전. 편대는 턴당 1회만 교전 |
| 적 선공 | 비행 중인 편대에 적이 맞닿으면 적이 교전을 건다 |
| 착륙 | 아군 거점 칸에 도착하면 착륙(소속 거점 변경 가능). 착륙한 턴에는 다시 이륙할 수 없다 |
| 연료 고갈 | 불시착 — 날던 기체는 손실. 적 영역이면 파일럿 포로 위험 |
| 귀환 | 자동으로 일어나지 않는다. "귀환" 버튼(가장 가까운 아군 거점 쪽으로 이번 턴 이동)과 "자동 귀환" 버튼(착륙할 때까지 매 턴 귀환 이동을 이어 감, 다른 명령을 내리면 해제)으로 반복 조작만 덜어 준다 |

- 보스·스토리 교전은 직접 플레이 필수, 나머지는 교전마다 직접/자동 정산 선택
- **겹침 보정 삭제**: v0.2의 "작전 지역이 겹치면 앞 전투가 뒤 전투를 약화"는 체감이 약하고 발생도 드물었다. 대신 적 거점 주변의 호위 부대·방공망(9장)을 여러 편대가 순서대로 벗겨내는 구조로 "순서가 전술"을 만든다

### 자동 정산

- 편대 전력과 적 전력을 비교해 결과 산출. 라운드마다 편대의 앞 기체가 싸우고, 손상이 교대 기준(60%)을 넘으면 다음 기체로 교대
- 기대값은 직접 플레이에 가깝지만 항상 약간 불리 (프로토타입 불리 계수 0.85 — 결과 카드만 보고 납득 가능했음)
- 파일럿 능력치가 결과를 크게 좌우 (에이스를 키우는 이유가 자동 정산에서도 생김)
- **최소 교전**: 교대 기준을 넘은 기체만 남아도 가장 덜 손상된 기체가 최소 1라운드는 싸운 뒤 철수한다 (프로토타입에서 비행 중 두 번째 교전·적 선공 때 0라운드 철수가 "대기만 하다 끝난 것처럼" 보인 결함)

### 출격하지 않는 편대

- 적이 **해당 편대가 주둔 중인 거점을 공격해 올 때에 한해** 자동 요격 (수치 정산)
- 하늘에 있는 편대는 거점을 지키지 않는다. 편대를 모두 내보낸 거점은 자동 요격이 없으며, 대공포·SAM만으로 방어
- 프로토타입에서는 거점 자체 방어가 강해 비워도 위험이 거의 없었다(출격하지 않는 봇도 거점 상실 0) → 거점 자체 방어 수치는 "편대 없이는 버티기 어려운" 쪽으로 낮춘다
- 기체 정비·파일럿 피로 회복 **로테이션** 대상 (출격하지 않은 턴에 피로 기본 회복)

## 4. 전략 맵

| 항목 | 내용 |
|---|---|
| 형태 | 헥스 타일, 2D 탑다운 |
| 진행 | 턴제 |
| 세력 | 다수 세력 난전. 적 세력끼리도 교전 |
| 시야 | 지형은 공개, 적 부대만 숨김. 거점 영역 + 1, 레이더 등급만큼 확대, 비행 중 편대 주변 2칸, 지상군·아군 자원 타일 주변 |
| 미확인 접촉 | 시야 밖이라도 거점 시야 + 2칸 안의 적 부대는 "?"로 표시 (정체·전력·수 모름, 지난 위치에서 온 방향 표시). 레이더가 없는 거점이 잡은 접촉은 위치가 최대 1칸 어긋남. "?"는 공격 목표가 아니며, 편대를 보내 시야에 넣어야 정체가 드러남. "?"의 진행 방향을 읽고 편대를 길목에 미리 보내 두는 플레이는 프로토타입 테스터가 재미를 느낀 요소 중 하나였다 |
| 편대 배치 | 거점에 주둔. 이륙하면 맵 위를 비행 (3장) |
| 재배치 | 거점 간 즉시 이동, 그 턴에는 출격 불가 |
| 자원 타일 | 4.1 참고 |
| 지형 | 해상 포함. 자원 타일 분포, 전투 스테이지 구성에 영향 |
| 규모 | 캠페인 전체가 하나의 대형 맵, 구역별 점진 개방 (10장 참조) |

### 지상군

| 항목 | 내용 |
|---|---|
| 구성 | 기갑·보병. 각각 등급과 수로만 처리 |
| 획득 | 거점의 병영에서 고용, 매 턴 유지비 |
| 소속 | 거점 소속. 평소에는 맵에 표시되지 않음 |
| 출동 | 출동 비용(무장 비용) 지불 후 맵에 표시. 목표 헥스는 플레이어가 지정, 이동·전투·점령은 AI |
| 이동 | 여러 턴에 걸쳐 이동, 이동 중 적의 공격 대상 (호위 미션으로 엄호) |
| 점령 후 | 플레이어가 선택. 일부를 점령 거점에 주둔시키고 나머지는 복귀 가능 |
| 등급 상승 | 병영 등급(상한), 연구, 자금으로 훈련·장비 개선 |

플레이어의 출격은 지상군이 들어갈 길을 열고, 이동 중인 지상군을 지키는 역할을 한다.

### 4.1 자원 타일

v0.2의 경제 시설 중 정유시설·광산을 맵 위의 중립 타일로 바꾸고(도시 추가), 금융은 폐지했다. 거점 안에서 수입 시설을 늘리면 수입이 폭증해 난이도가 무너졌고(전략 프로토타입 S3), 빼앗길 수 있는 수입원이 전선을 만든다.

| 항목 | 내용 (수치는 프로토타입 값) |
|---|---|
| 종류 | 유전(정유) 80 / 광산 50 / 도시 60 — 턴당 수입 × 등급 |
| 획득 | 지상군이 들어가면 점령 (수비대 없음). 적 지상군도 점령한다 |
| 등급 | 1~3. 소유자가 자금으로 올림 |
| 폭격 | 적 소유 타일을 폭격하면 등급 −1 (0이 되면 중립). 등급만큼 대공·구조물 |
| 시야 | 아군 타일 주변 1칸 |
| 제약 | 전초기지를 자원 타일 위에 지을 수 없다 |

### 4.2 비행 운용

| 항목 | 내용 (수치는 프로토타입 값) |
|---|---|
| 초계 | 아군 영역 위에서 턴을 마치면 연료 소모 없음 → 레이더 "?"를 보고 길목에서 기다리는 플레이 |
| 드롭탱크 | 3장 출격 규칙. 비용 없음, 교전·공격 도착 때 투하 |
| 공중 급유기 호출 | 지점을 골라 호출(비용 150) → 그 턴의 적 턴에 도착 → 다음 내 턴에 주변 1칸 비행 편대 급유(연료 가득, 편대당 1회) → 그 턴 끝에 떠남 |
| 급유기 수·거리 | 활주로 2등급 이상 거점마다 1대, 그 거점에서 6칸(보급창고 +2) |
| 급유기 위험 | 적이 탐지하고 닿을 수 있으면 다가와 격추, 공중 전력 있는 적이 맞닿아도 격추. 호출 화면에 대공 위협 범위를 표시 |

원거리 원정에서는 적 이동 경로와 급유 지점이 출격·이동의 큰 고려 요소가 되었다 (전략 프로토타입 S1).

## 5. 거점 시스템

### 5.1 거점 종류

| 종류 | 설명 |
|---|---|
| 고유 거점 | 맵에 고정된 대형 시설. 건설 불가, 점령으로만 획득. 같은 계열 건설 시설보다 강하고 고유 특수 효과 보유. 등급 2~3 상태로 존재 |
| 범용 거점 | 점령하거나 전초기지로 건설할 때 용도를 선택. 등급 1부터 시작 |

**고유 거점 예시**

| 고유 거점 | 특수 효과 방향 |
|---|---|
| 민간 공항 | 처음부터 대형 활주로 보유 (대형 기체 운용 가능), 주둔 편대 +1 |
| 대도시 | 큰 고정 수입, 상부 예산 증가 |
| 유전 단지 | 대량 수입, 영역 연료 비용 대폭 할인 |
| 조기경보 레이더 기지 | 광역 탐지, 적 부대 이동 예측 표시 |
| 군수 공장 | 기체·무장 구매 할인 또는 개조 상한 증가 |

### 5.2 등급

거점은 맵의 **칸 하나**다. 거점 등급은 **건설 가능한 시설 종류**, **시설 규모 상한**(시설 등급의 합), **영역 반경**을 정한다.
주둔 편대 수는 격납고 등급이, 운용 기체는 활주로 등급과 정비소 등급이 결정한다 (5.4 참조).

| 등급 | 명칭 | 시설 규모 상한 (예시) | 영역 반경 | 해금 시설 |
|---|---|---|---|---|
| 1 | 전초기지 | 3 | 1 | 격납고, 활주로, 병영, 대공포 |
| 2 | 기지 | 5 | 1 | + 정비소, 레이더, 보급창고, 유흥가 |
| 3 | 거점 | 8 | 2 | + 무기고·개조 공방, SAM |
| 4 | 사령부 | 12 | 2 | + 연구소 |

- 등급 상승 조건: 자금 + 특정 시설 보유 (예: 3등급은 정비소·레이더 필요). 상승 비용 예시 300 / 700 / 1500
- 상한을 넘겨 짓거나 올릴 수는 있으나 넘친 만큼 비용 할증 (프로토타입: +50%)
- 연구소를 4등급에 두어 "사령부 하나를 키울 것인가, 거점을 여럿 둘 것인가"라는 선택을 만든다

### 5.3 영역

- 영역은 거점 등급에 따라 **자동**으로 정해진다 (1~2등급 반경 1, 3~4등급 반경 2). 칸 단위 영역 확장은 폐지
- 영역은 시야·초계(연료 소모 없음)·잔해 회수 범위의 기준
- 폐지 이유: 칸 단위 확장은 지형과 적 공격 루트를 고민하는 재미가 있었으나, 짧은 작전 반경과 충돌했다 — 출격한 편대가 넓힌 자기 영역조차 못 벗어나는 경우가 생김(전략 프로토타입 S4). 반경을 키우면 적 기지에 바로 닿아 빌드업이 무의미해짐
- **작전 반경 기준**: 가장 짧은 기체도 자기 영역 + 2칸 이상 (맵 크기와 함께 조정)

### 5.4 시설

거점마다 시설은 **종류당 하나**. 시설 등급은 거점 등급과 독립된 1~4등급이며, 모든 시설 등급의 합이 시설 규모 상한(5.2)에 걸린다.

| 계열 | 시설 | 역할 | 등급 | 등급이 올리는 것 |
|---|---|---|---|---|
| 군사 | 격납고 | 편대 주둔 | 있음 | 주둔 편대 수 (등급 × 2) |
| 군사 | 활주로 | 운용 가능한 기체 크기, 급유기 | 있음 (1~3) | 운용 기체 크기 (1 소형 / 2 중형 / 3 대형). 2등급부터 급유기 호출 |
| 군사 | 정비소 | 기체 수리 | 있음 | 운용 가능 기체 티어(1~4), 수리 속도 |
| 군사 | 무기고·개조 공방 | 부품 개조, 무장 관리 | 없음 | — |
| 군사 | 병영 | 지상군 고용 | 있음 | 지상군 등급 상한 |
| 지원 | 레이더 | 탐지 | 있음 | 탐지 반경 |
| 지원 | 대공포·SAM | 거점 방어 | 있음 | 방어력 |
| 지원 | 연구소 | 연구 포인트 산출 | 있음 | 산출량 |
| 지원 | 보급창고 | 해당 거점 출격 시 연료·탄약 비용 할인, 작전 반경 소폭 증가, 급유기 거리 +2 | 없음 | — |
| 경제 | 유흥가 | 수입 + 해당 거점 주둔 파일럿의 피로 회복 가속 | 있음 | 급여 환수율, 회복 가속 |

정유시설·광산·금융은 거점 시설에서 빠지고, 정유·광산은 맵의 자원 타일(4.1)이 됐다. 금융은 폐지 (등급이 오를수록 수입이 폭증해 난이도를 무너뜨림).

### 5.4.1 유흥가

- 용병 파일럿들이 급여를 쓰는 술집·유흥가. 사람의 회복은 기계 정비(정비소)와 분리
- **수입**: 해당 거점에 주둔한 파일럿 급여의 일부가 되돌아옴. 등급이 오를수록 환수율 증가
- **회복**: 해당 거점 주둔 파일럿의 피로 회복 가속. 등급 비례
- 파일럿이 많은 대형 편대 기지일수록 가치가 커지며, 거점 안에 남은 유일한 수입 시설

### 5.4.2 활주로

- 활주로 등급 = 운용 가능한 최대 기체 크기 (1 소형 / 2 중형 / 3 대형)
- v0.2의 "직선 연속 헥스 = 길이" 요건은 거점이 칸 하나가 되면서 폐지
- 활주로 등급도 시설 규모 상한을 먹는다 → 대형 기체 기지일수록 다른 시설을 덜 키우는 구조

### 5.4.3 기체 운용 제한 요약

| 제한 축 | 결정 요소 |
|---|---|
| 기체 크기 | 활주로 등급 |
| 기체 티어 | 정비소 등급 |
| 주둔 편대 수 | 격납고 등급 × 2 |

### 5.5 신규 거점 획득

- **점령**: 적·중립 거점을 지상군으로 점령. 고유 거점은 이 방법으로만 획득
- **전초기지 건설**: 아군 거점에서 3칸 이상 떨어지고, 편대가 (드롭탱크 포함) 왕복할 수 있는 칸에 건설. 자원 타일 위는 불가. 등급 1로 시작, 건설 시 용도 선택. 비용이 높아 남발이 어렵다 (프로토타입 600 + 거리당 50). 작전 반경을 전진시키는 수단

### 5.6 거점을 빼앗길 때

1. 거점 등급 1 하락
2. 하락한 등급의 시설 종류·규모 상한을 넘는 시설은 파괴(등급 하락)되고, 파괴분은 점령자의 전리품이 됨
3. 주둔 편대는 인근 아군 거점으로 강제 이탈. 받아줄 슬롯이 없으면 기체 손실. 비행 중이던 소속 편대는 착륙할 곳을 찾아야 함
4. 영역은 거점과 함께 넘어가며, 유지비도 점령자가 부담

**초토화**: 점령당하기 직전 턴에 시설을 스스로 파괴해 적의 전리품을 없앨 수 있다. 대신 되찾아도 빈 거점이 된다.

## 6. 유닛 — 기체·파일럿·편대

### 6.1 편대

- 규모: 2기로 시작, 최대 4기 (거점·연구로 확장)
- 출격 단위이자 전투 중 교체 가능한 기체 풀

### 6.2 기체

| 항목 | 내용 |
|---|---|
| 역할 | 제공기 / 공격기 / 다용도기 / 폭격기 |
| 크기 | 소형 / 중형 / 대형. 활주로 등급으로 운용 제한 |
| 비행 성능 | 속도(턴당 칸), 작전 반경(→ 연료). 편대는 가장 느린 기체·가장 짧은 반경 기준 |
| 티어 | 1~4티어. 정비소 등급으로 운용 제한 |
| 획득 | 상점 구매, 연구 해금 후 구매, 전리품·노획, 상부 보급 |
| 개조 | 부품 슬롯(엔진·장갑·전자장비 등) + 단계 강화. 3D 모델에 외형 반영 |
| 무장 | 하드포인트에 장착, 탄약은 출격마다 비용 소모 |
| 귀환 후 손상 | 유지되며 수리 비용·턴 소요 |
| 격추 | 아군 영역: 잔해 회수로 복구 가능 / 적 영역: 영구 손실 (개조·부품 포함) |

### 6.3 파일럿

| 구분 | 내용 |
|---|---|
| 네임드 에이스 | 이름 있는 개별 유닛. 스킬·성장·피로 보유. 소수 |
| 일반 파일럿 | 숙련도·피로만 가진 간단한 자원 |
| 기체와의 관계 | 자유 교체. 단, 파일럿마다 숙련 기종(적성)이 있어 맞는 기체에서 이득 |
| 에이스 획득 | 스토리 합류, 자금으로 고용, 일반 파일럿의 성장·승격, 적 에이스 포로 영입 |
| 비용 | 고용비 + 전원 턴당 급여 |
| 피로 | 출격 시 누적, 하늘에서 턴을 마칠 때마다·교전마다 누적, 거점에서 보낸 턴마다 기본 회복. 유흥가가 있는 거점에서는 회복 가속 |
| 로테이션 | 손상·피로 누적으로 지친 편대를 내리고 다른 편대를 올리는 운용. 자금이 모자라고 적이 자주 올수록 압박이 커짐 (전략 프로토타입 S6 — 압박 수단으로 작동) |

### 6.4 격추와 탈출

- 기체가 격추되면 파일럿은 탈출한 것으로 처리 (영구 사망 없음)
- 가장 가까운 아군 거점까지의 거리에 따라 복귀 시간 발생
- 파일럿 능력치가 복귀 시간에 관여할 가능성은 열어둠
- 적 영역 상공에서 탈출하면 포로가 될 수 있음 → **구출 출격** 또는 **몸값 지불**로 해결
- **연료 고갈 불시착**도 격추와 같이 처리 (기체 손실, 위치에 따라 포로 위험)
- 포로·영구 손실은 프로토타입에서 거의 발생하지 않아 체감을 확인하지 못했다. 발생 시 디브리핑에서 크게 보이게 하고, 빈도는 본 게임 밸런싱에서 재확인
- 이 규칙은 적 파일럿에게도 대칭 적용 (적 에이스 포로·영입의 근거)

## 7. 출격 & 슈팅 전투

### 7.1 기본 규칙

| 항목 | 내용 |
|---|---|
| 스테이지 길이 | 미션 종류별 2~10분 (최대 10분) |
| 스크롤 | 강제 스크롤 + 플레이어 가감속. **가로 입력 = 스크롤 속도** (모드 B: 앞 = 가속, 뒤 = 감속, 놓으면 속도 유지. 순항 속도 복귀는 옵션). 테스터 2명 모두 "속도감"으로 바로 이해 |
| 세로 | 화면 2.5배 높이의 세로 맵, 카메라는 부드럽게 추적(0.2초) |
| 조작 대상 | 편대 내 기체 1기 (실시간 전환) |
| 기체 전환 | 탭 = 다음 기체, 홀드 = 링 메뉴로 원하는 기체. 전환 시 무방비 0.5초 (발사 불가, 세로 이동 감속) — 부담 없음으로 확인. 링 메뉴 슬로모션은 의견이 갈려 조작 설정 항목으로 |
| 레이더 | 화면 밖 적 위치 표시 필수 (세로 띠 방식 기본). 시선 분산을 줄이도록 위협만 강조하고 화면 가장자리 진입 예고를 병행 |
| 선회 | 선회 구역(보스전)은 양 끝에서 자동 선회(약 1.2초). 임의 선회 허용 여부는 스테이지 속성 — 선회 구역·보스전에서 허용, 일반 진행 구간은 자동 선회만 |
| 지형 충돌 | 큰 피해(즉사 후보)로 긴장감을 주되, 전방 지형 예고(레이더·경고 표시)를 반드시 함께. 고속에서 반응할 수 없는 급경사는 레벨 디자인에서 금지 |
| 전경 기체 격추 | 다음 기체 자동 투입 (무방비 시간 포함) |
| 철수 | 구간 경계의 이탈 지점에서만 가능. 보스 직전에는 반드시 배치 |
| 결과 판정 | 목표 파괴율에 비례해 전략 맵에 효과 반영 |

### 7.2 비조작 기체 — 배경 레이어

- 조작하지 않는 기체는 횡스크롤 뒤쪽 레이어에서 연출용 가상 전투를 한다
- 실제 전투에 영향을 주지 않으며 피해도 입지 않는다
- 전투 종료 후, 전경에 나오지 않은 시간에 비례해 가벼운 손상을 입는다
- 경험치는 소량 획득

**설계 메모**: 한 번에 1기만 전경에 있으므로 편대 전체의 대기 시간 합은 (편대 기체 수 − 1) × 스테이지 시간으로 일정하다. 전환 방식은 경손상의 분배만 바꾸며, 편대를 크게 꾸릴수록 출격당 총 정비 부담이 커진다.

### 7.3 스테이지 구성

- **헥스 지형 × 미션 종류 × 적 단계**로 배경, 대공 배치, 적 구성이 결정된다
- 스토리·고유 거점 스테이지: 수작업 제작
- 일반 스테이지: 구간(청크) 모듈 조합 절차 생성
- 이탈 지점은 청크 사이 구간 경계에 배치

### 7.4 미션 종류

| 목적 | 미션 | 길이 | 보스 | 파괴율 → 전략 효과 |
|---|---|---|---|---|
| 적 부대 격파 | 부대 공격 | 4~6분 | 적 주력일 때만 | 적 부대 전력 감소 |
| 거점 공격 | 거점 폭격 | 6~10분 | 있음 | 대공·시설 파괴 → 아군 점령 성공률 상승, 일정 이상이면 등급 하락 |
| 아군 거점 방어 | 요격 | 4~6분 | 대규모 공세일 때만 | 격추율만큼 아군 거점 피해 감소 |
| 특수 | 정찰 | 2~3분 | 없음 | 진행 거리만큼 주변 적 부대 공개 (수 턴 유지) |
| 특수 | 호위 | 4~6분 | 없음 | 아군 수송기·폭격기·이동 중 지상군의 생존율만큼 보급·폭격·진격 효과 |
| 특수 | 보급선 차단 | 3~5분 | 없음 | 적 부대 보급 감소 (이동력·회복 저하) |
| 특수 | 구출 | 3~5분 | 없음 | 구출기 생존 시 포로 파일럿 귀환 |

- 주둔 편대의 **자동 요격**(적 턴, 해당 거점 피습 시 수치 정산)과 **요격 미션**(플레이어 출격)은 별개
- 다턴 비행에서 교전은 이륙 1회당 여러 번 일어날 수 있다 (턴당 1회). 미션 종류는 교전 칸의 목표(적 부대 / 적 거점 / 적 자원 타일)로 정해진다. 자원 타일 폭격은 거점 폭격의 짧은 변형

## 8. 경제 & 성장

### 8.1 자원

자금 단일. 연료·탄약은 별도 자원이 아닌 출격 비용 항목.

### 8.2 수입

| 수입원 | 내용 |
|---|---|
| 상부 예산 | 턴당 지급, 신뢰도에 따라 증감 |
| 자원 타일 | 유전·광산·도시 (4.1). 빼앗길 수 있는 수입 — 수입의 주축 |
| 경제 시설 | 유흥가(주둔 파일럿 급여 환수) |
| 전과 보상 | 목표 파괴율 비례 + 특별 표적 현상금 (적 에이스·보스) |
| 점령 | 점령 보상, 전리품 (파괴된 시설 포함) |

### 8.3 지출

- 고정비 (매 턴): 거점 유지비(거점 등급 합 × 25, 프로토타입 값 — 거점 수에 누진하는 방식 검토), 파일럿 전원 급여, 지상군 유지비
- 성장: 시설 건설·등급 상승, 거점 등급 상승, 전초기지 건설, 자원 타일 등급 상승, 연구
- 전력: 기체·부품·무장 구매, 파일럿 고용비, 지상군 고용·훈련·장비 개선
- 출격: 편대 연료·탄약(이륙 때), 급유기 호출, 지상군 출동 비용(무장 비용)
- 손실: 수리, 몸값

**밸런싱 기준 (프로토타입 결과로 개정)**: v0.2는 "몇 턴 연속 적자면 파산하는가"를 기준선으로 삼았으나, 세 버전 모두 파산 기준(2·3·4턴)이 결과를 바꾸지 못했다. 고정비 압박은 초반에만 작동하고, 수입 시설을 늘린 중반부터는 수입이 폭증해 난이도가 무너졌다(도시판 시뮬레이션: 100턴 동안 적자 0회).
- 긴장의 주축은 **상부 신뢰도와 지시**로 둔다. 파산은 패배 조건으로 남기되 기준선이 아니다
- 수입은 빼앗길 수 있는 것(자원 타일·거점) 위주로 하고, 확장할수록 유지비가 누진되게 해서 "벌수록 지킬 것이 늘어나는" 구조로 만든다
- 시작 자금은 빡빡하게 (프로토타입 테스터: 1000은 빡빡, 2000을 기본값으로 채택)

### 8.4 상점

- 상시 전 품목 구매 가능
- 실제 구매는 거점 등급(기체 티어)과 연구 해금으로 제한되며, 잠긴 품목은 사유를 표시

### 8.5 연구

| 항목 | 내용 |
|---|---|
| 구조 | 기술 트리 + 역설계 |
| 진행 재원 | 연구 포인트 + 자금 병행 |
| 연구 포인트 공급 | 연구소(4등급), 역설계, 전과 |
| 역설계 대상 | 노획 기체, 적 에이스 전용기, 점령 거점의 시설·장비 |
| 흐름 | 초반은 역설계·전과의 적은 포인트로 천천히 진행하며 상점·상부 보급으로 버틴다. 사령부 건설 후 본격 가속 (중반 전환점) |

### 8.6 상부 신뢰도와 지시 임무

| 항목 | 내용 |
|---|---|
| 지시 형태 | 상시 장기 목표 1개 + 전황 이벤트로 발생하는 긴급 지시 |
| 긴급 지시 기한 | N턴 이내, 초과 시 실패 처리 |
| 지시 종류 (프로토타입) | 적 부대 격파, 거점 점령, 거점 등급 올리기, 자원 타일 확보, 지정 거점 방어 |
| 출격 강제 | 방어만 하며 기다리는 플레이를 깨기 위해, 긴급 지시는 원거리 출격이 필요한 목표를 자주 낸다 (전략 프로토타입 S1) |
| 신뢰도 상승 | 지시 임무 성공, 거점·자원 타일 확보 |
| 거부·실패 | 신뢰도 하락 + 예산 삭감 |
| 신뢰도 바닥 | 해임 (게임 오버) |

신뢰도는 전과와 손실 최소화를 반영하지 않는다. 상부는 명령 이행과 영토만 본다. 거점 확보는 신뢰도를 올리지만 유지비를 키운다.

| 항목 | 내용 |
|---|---|
| 세력 차별화 | 기체는 공유, 교리(전투 스타일)로 구분. 일부 에이스만 고유 기체 |
| 전략 AI | 세력별 성향 + 전황에 따른 태세 변경. 적 세력 간 교전. 목표는 아군 거점·자원 타일·탐지한 급유기 |

| 거점 방어 구성 | 적 거점 주변 칸에 호위 편대·지상군·방공망을 붙여, 여러 편대가 순서대로 벗겨내게 한다 (겹침 보정을 대체, 3장) |
| 적 단계 | 적 부대·거점 전력 + 캠페인 진행 단계 |
| 보스 | 대형 지상 병기(요새·열차포·육상전함), 대형 항공기(거대 폭격기·공중항모), 해상 전력(항모·전함). 큰 목표에만 등장 |

### 9.1 라이벌 에이스

- 세력별 네임드 라이벌, 반복 등장하며 성장
- 전략 맵에 라이벌이 이끄는 부대가 표시되고, 해당 세력과 교전 시 확률로 스테이지에 난입
- 보스가 아닌 **스테이지 도중 난입 위협**으로 기능
- 격추 시 탈출 규칙 적용 → 복귀 후 재등장, 아군(플레이어) 영역 상공에서 탈출하면 포로·영입 가능

### 9.2 세력 교리 방향 (예시, 콘텐츠 단계에서 확정)

물량으로 밀어붙이는 세력, 대공망·요새화로 버티는 세력, 보급선을 노리는 세력, 약해진 쪽만 골라 치는 기회주의 세력.

## 11. UI/UX

### 11.1 전략 맵 (메인 허브)

- 2D 탑다운 헥스 맵이 항상 바탕, 나머지 화면은 패널로 열림
- 상단 바: 자금, 이번 턴 예상 수지(수입 − 유지비 − 급여), 상부 신뢰도, 턴
- 맵 표시: 영역 경계, 거점 등급, 자원 타일(소유·등급), 비행 중 편대(연료), 편대 작전 반경, 탐지된 적 부대, 미확인 접촉 "?", 급유기, 라이벌 부대
- 이동 재생: 아군 편대와 적 부대의 이동을 칸 단위로 맵 위에 재생 (건너뛰기 가능)
- **사용 편의성**: 프로토타입 테스터들이 UI를 어렵다고 했다. 본 게임 UI는 흐름·정보 위계를 따로 설계하며 프로토타입 패널 배치를 옮기지 않는다

### 11.2 운영 패널

| 패널 | 기능 |
|---|---|
| 거점 관리 | 시설 건설, 영역 확장, 등급 상승 조건, 초토화 명령 |
| 격납고 | 편대 편성, 기체 손상·경손상, 부품 개조, 하드포인트 무장 |
| 파일럿 명부 | 숙련 기종, 피로(회복 예상 턴), 복귀 대기, 포로(구출/몸값) |
| 상점 | 구매, 잠금 사유 표시 |
| 연구 | 기술 트리, 역설계 대기 목록 |
| 지상군 | 고용·강화, 출동(목표 헥스 지정), 이동 중 부대 현황, 점령 후 주둔/복귀 배분 |
| 상부 통신 | 장기 목표, 긴급 지시와 남은 기한, 신뢰도 변동 내역 |

### 11.3 출격 흐름

1. **편대 명령**: 편대를 고르면 이번에 갈 수 있는 칸(속도·연료)과 공격 가능한 칸이 표시됨. 칸을 고르면 이륙·이동이 재생됨. 비행 중 편대에는 연료·가장 가까운 착륙 거점·연료 경고, [귀환] [자동 귀환] [급유] 버튼. 편대가 모두 빠지는 거점은 "방어 공백" 경고
2. **브리핑** (교전 1건마다): 미션 종류, 지형, 적 단계, 보스 유무, 라이벌 출현 가능성, 포로 위험 구역 여부, 직접/자동 정산 선택
3. **편성 확인**: 편대 내 기체 순서
4. **전투 HUD** (직접 플레이): 편대 기체 아이콘(전환·무방비 표시), 파괴율 게이지, 다음 이탈 지점까지 거리, 레이더, 라이벌 난입 경고
   **자동 정산**: 결과 요약 카드로 즉시 표시
5. **디브리핑**: 파괴율과 전략 효과, 보상, 손상·경손상, 격추·탈출·포로, 경험치, 역설계 획득물
6. 다른 편대 명령으로 → 턴 종료(연료 경고가 있으면 확인) → 아군 지상군 AI → 적 이동 재생 → **적 턴 요약** (자동 요격, 적 선공 교전, 급유기 격추, 거점·자원 타일 피해, 지상군 피습, 세력 간 교전)

### 11.4 조작

- 게임패드 기준: 숄더 버튼으로 패널 탭 전환, 스틱 커서 + 헥스 스냅 이동, 확인 동작 한 버튼 통일
- PC: 마우스로 헥스 직접 선택 병행
- 전투 패드 기본 배치 = 트리거 스로틀 (RT 가속 / LT 감속, South 기관포, East 하드포인트, West·North 무장 선택, LB 탭·홀드 기체 전환, RB 임의 선회). 키보드도 플레이 가능 확인
- 버튼을 모를 때 답답하다는 응답 → 첫 출격에 버튼 안내(화면 표시·튜토리얼) 필수
