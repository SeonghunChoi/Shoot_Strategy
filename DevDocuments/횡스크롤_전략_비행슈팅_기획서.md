## 2. 핵심 설계 원칙

**얼마나 내보내고, 얼마나 남길 것인가.**
출격 가능한 편대는 모두 출격할 수 있지만, 내보낸 편대의 거점은 자동 요격 없이 비게 된다. 매 턴의 질문은 "어디를 칠 것인가"이자 "어디를 비워둘 것인가"다.

**순서가 전술이다.**
같은 턴의 출격은 플레이어가 정한 순서대로 진행되며, 앞 출격의 결과가 뒤 출격을 바꾼다.

**지휘관은 늘 돈이 모자란다.**
영역 유지비와 파일럿 급여라는 무거운 고정비가 매 턴 빠져나간다. 쉬는 턴도 손해다.

**손실의 무게는 위치가 정한다.**
아군 영역 위에서 격추되면 잔해를 회수할 수 있지만, 적진 깊숙이 들어가면 기체는 영구 손실이고 파일럿은 포로가 될 수 있다.

**땅은 한정되어 있다.**
영역 헥스 1칸에는 시설 1개. 격납고·활주로·경제 시설이 같은 땅을 두고 경쟁한다.

**편대는 교체 가능한 기체 풀이다.**
화면에는 늘 1기만 싸운다. 어떤 기체를 묶어 보낼지가 전투의 전술이 된다.

**상부는 결과만 본다.**
상부 신뢰도는 전과가 아니라 명령 이행과 영역 확대로만 오른다. 신뢰를 잃으면 해임된다.

## 3. 코어 루프

턴 내부의 정보 확인·운영·명령은 자유 순서로 진행하며, 출격은 생략할 수 있다.

| 단계 | 내용 |
|---|---|
| 정보 | 탐지 범위 내 적 부대 이동, 거점 위협, 상부 지시 확인 |
| 운영 | 거점 건설·확장·등급 상승, 시설 등급 상승, 기체 구매·개조, 편대 편성, 지상군 고용·강화 |
| 명령 | 지상군 출동 (목표 헥스 지정, 출동 비용 지불) |
| 출격 계획 (선택) | 출격할 편대별 목표 헥스 지정, 직접/자동 정산 선택, 출격 순서 결정 |
| 출격 실행 | 정한 순서대로 1건씩 전투·정산. 앞 결과가 뒤 출격에 반영 |
| 정산 | 전과 보상, 기체 손상·손실, 파일럿 경험치·탈출·포로 처리 |
| 턴 종료 → 아군 AI | 지상군이 지정 목표로 이동·전투·점령 |
| 적 턴 | 적 세력 이동·공격, 세력 간 교전, 이동 중 아군 지상군 공격, 편대 주둔 거점의 자동 요격 |

### 출격 목적

- 적 부대 격파
- 적 거점 공격 / 점령 지원
- 아군 거점 방어
- 특수: 정찰, 호위, 보급선 차단, 구출

### 출격 규칙

- 출격 가능한 기체·파일럿이 있는 편대는 모두 같은 턴에 출격할 수 있다
- **작전 지역** = 목표 헥스 + 인접 6헥스. 한 작전 지역에는 1개 편대만 출격
- 목표 헥스가 다르면 작전 지역이 겹쳐도 출격 가능. 먼저 치른 전투의 결과가 겹치는 뒤 전투의 적 난이도 또는 적 기체 수를 줄인다 (보스에게는 영향 없음)
- 출격 순서는 플레이어가 정하고, 순차로 출격·정산한다 (예: 정찰로 적을 드러낸 뒤 공격, 대공망을 먼저 깎고 폭격)
- 보스·스토리 출격은 직접 플레이 필수, 나머지는 편대별로 직접/자동 정산 선택

### 자동 정산

- 편대 전력과 적 전력을 비교해 결과 산출
- 기대값은 직접 플레이에 가깝지만 항상 약간 불리
- 파일럿 능력치가 결과를 크게 좌우 (에이스를 키우는 이유가 자동 정산에서도 생김)

### 출격하지 않는 편대

- 적이 **해당 편대가 주둔 중인 거점을 공격해 올 때에 한해** 자동 요격 (수치 정산)
- 편대를 모두 내보낸 거점은 자동 요격이 없으며, 대공포·SAM만으로 방어
- 기체 정비·파일럿 피로 회복 **로테이션** 대상 (출격하지 않은 턴에 피로 기본 회복)

## 4. 전략 맵

| 항목 | 내용 |
|---|---|
| 형태 | 헥스 타일, 2D 탑다운 |
| 진행 | 턴제 |
| 세력 | 다수 세력 난전. 적 세력끼리도 교전 |
| 시야 | 지형은 공개, 적 부대만 숨김. 거점 영역·레이더·정찰로 탐지 |
| 편대 배치 | 거점에 주둔, 해당 거점의 작전 반경 내 헥스로만 출격 |
| 재배치 | 거점 간 이동 가능, 턴 소모 |
| 지형 | 해상 포함. 경제 시설 일부의 입지 조건, 전투 스테이지 구성에 영향 |
| 규모 | 캠페인 전체가 하나의 대형 맵, 구역별 점진 개방 (10장 참조) |

### 지상군

| 항목 | 내용 |
|---|---|
| 구성 | 기갑·보병. 각각 등급과 수로만 처리 |
| 획득 | 거점의 병영에서 고용, 매 턴 유지비 |
| 소속 | 거점 소속. 평소에는 맵에 표시되지 않음 |
| 출동 | 출동 비용(무장 비용) 지불 후 맵에 표시. 목표 헥스는 플레이어가 지정, 이동·전투·점령은 AI |
| 이동 | 여러 턴에 걸쳐 이동, 이동 중 적의 공격 대상 (호위 미션으로 엄호) |
| 점령 후 | 플레이어가 선택. 일부를 점령 거점에 주둔시키고 나머지는 복귀 가능 |
| 등급 상승 | 병영 등급(상한), 연구, 자금으로 훈련·장비 개선 |

플레이어의 출격은 지상군이 들어갈 길을 열고, 이동 중인 지상군을 지키는 역할을 한다.

## 5. 거점 시스템

### 5.1 거점 종류

| 종류 | 설명 |
|---|---|
| 고유 거점 | 맵에 고정된 대형 시설. 건설 불가, 점령으로만 획득. 같은 계열 건설 시설보다 강하고 고유 특수 효과 보유. 등급 2~3 상태로 존재 |
| 범용 거점 | 점령하거나 전초기지로 건설할 때 용도를 선택. 등급 1부터 시작 |

**고유 거점 예시**

| 고유 거점 | 특수 효과 방향 |
|---|---|
| 민간 공항 | 처음부터 대형 활주로 보유 (대형 기체 운용 가능), 주둔 편대 +1 |
| 대도시 | 큰 고정 수입, 상부 예산 증가 |
| 유전 단지 | 대량 수입, 영역 연료 비용 대폭 할인 |
| 조기경보 레이더 기지 | 광역 탐지, 적 부대 이동 예측 표시 |
| 군수 공장 | 기체·무장 구매 할인 또는 개조 상한 증가 |

### 5.2 등급

거점 등급은 **건설 가능한 시설 종류**와 **시설 총개수 상한**을 제한한다. 영역 크기는 제한하지 않는다.
주둔 편대 수는 격납고 개수가, 운용 기체는 활주로 길이와 정비소 등급이 결정한다 (5.4 참조).

| 등급 | 명칭 | 시설 총개수 상한 (예시) | 해금 시설 |
|---|---|---|---|
| 1 | 전초기지 | 3 | 격납고, 활주로, 병영, 대공포 |
| 2 | 기지 | 5 | + 정비소, 레이더, 보급창고, 유흥가, 정유시설, 광산 |
| 3 | 거점 | 8 | + 무기고·개조 공방, SAM |
| 4 | 사령부 | 12 | + 연구소, 금융 |

- 등급 상승 조건: 자금 + 특정 시설 보유 (예: 3등급은 정비소·레이더 필요)
- 영역을 상한보다 넓게 확장할 수는 있으며, 시설이 없는 헥스도 시야·대공 범위 확대 효과는 가짐
- 연구소를 4등급에 두어 "사령부 하나를 키울 것인가, 넓게 퍼질 것인가"라는 선택을 만든다

### 5.3 영역 확장

- 거점 주변 헥스로 영역을 넓힌다
- 영역 헥스 1개당 시설 1개 건설 가능
- 영역이 넓을수록 시야·대공 방어 범위 확대
- 제한 장치: 확장할수록 비용이 누진 증가 + 영역 크기에 비례한 매 턴 유지비

### 5.4 시설

시설 등급은 거점 등급과 독립된 1~4등급. 등급이 올라가면 수치가 커지는 시설에만 등급이 있다.

| 계열 | 시설 | 역할 | 등급 | 등급이 올리는 것 |
|---|---|---|---|---|
| 군사 | 격납고 | 편대 주둔. 헥스 1개당 2개 편대 | 없음 | — |
| 군사 | 활주로 | 운용 가능한 기체 크기 | 없음 | 직선 연속 헥스 수로 길이 결정 |
| 군사 | 정비소 | 기체 수리 | 있음 | 운용 가능 기체 티어(1~4), 수리 속도 |
| 군사 | 무기고·개조 공방 | 부품 개조, 무장 관리 | 없음 | — |
| 군사 | 병영 | 지상군 고용 | 있음 | 지상군 등급 상한 |
| 지원 | 레이더 | 탐지 | 있음 | 탐지 반경 |
| 지원 | 대공포·SAM | 거점 방어 | 있음 | 방어력 |
| 지원 | 연구소 | 연구 포인트 산출 | 있음 | 산출량 |
| 지원 | 보급창고 | 해당 거점 출격 시 연료·탄약 비용 할인, 작전 반경 소폭 증가 | 없음 | — |
| 경제 | 유흥가 | 수입 + 해당 거점 주둔 파일럿의 피로 회복 가속 (지형 제한 없음) | 있음 | 급여 환수율, 회복 가속 |
| 경제 | 정유시설 | 수입 + 영역 연료 비용 할인 (유전 지형 필요) | 있음 | 수입·할인율 |
| 경제 | 광산 | 수입 + 수리·개조 비용 할인 (산악 지형 필요) | 있음 | 수입·할인율 |
| 경제 | 금융 | 보유 자금 비례 이자형 수입 | 있음 | 이율 |

### 5.4.1 유흥가

- 용병 파일럿들이 급여를 쓰는 술집·유흥가. 사람의 회복은 기계 정비(정비소)와 분리
- **수입**: 해당 거점에 주둔한 파일럿 급여의 일부가 되돌아옴. 등급이 오를수록 환수율 증가
- **회복**: 해당 거점 주둔 파일럿의 피로 회복 가속. 등급 비례
- 파일럿이 많은 대형 편대 기지일수록 가치가 커지며, 지형 제한이 없는 유일한 초중반 수입 시설

### 5.4.2 활주로

- 활주로 헥스는 **직선으로 연속**되어야 길이로 인정
- 기체 크기별 필요 길이: 소형 1칸 / 중형 2칸 / 대형(폭격기 등) 3칸
- 지형 제한은 없으나, 직선 요건 때문에 산악·해안이 섞인 영역에서는 긴 활주로 확보가 어려움
- 활주로와 격납고가 경제 시설과 같은 땅을 두고 경쟁 → 대형 기체 기지일수록 수입이 줄어드는 구조

### 5.4.3 기체 운용 제한 요약

| 제한 축 | 결정 요소 |
|---|---|
| 기체 크기 | 활주로 길이 |
| 기체 티어 | 정비소 등급 |
| 주둔 편대 수 | 격납고 개수 × 2 |

### 5.5 신규 거점 획득

- **점령**: 적·중립 거점을 지상군으로 점령. 고유 거점은 이 방법으로만 획득
- **전초기지 건설**: 자기 영역 가장자리 헥스에만 건설 가능, 등급 1로 시작, 건설 시 용도 선택. 비용이 높아 남발이 어렵다. 작전 반경을 전진시키는 수단

### 5.6 거점을 빼앗길 때

1. 거점 등급 1 하락
2. 하락한 등급의 시설 종류·총개수 상한을 넘는 시설은 파괴되고, 파괴분은 점령자의 전리품이 됨
3. 주둔 편대는 인근 아군 거점으로 강제 이탈. 받아줄 슬롯이 없으면 기체 손실
4. 영역은 거점과 함께 넘어가며, 유지비도 점령자가 부담

**초토화**: 점령당하기 직전 턴에 시설을 스스로 파괴해 적의 전리품을 없앨 수 있다. 대신 되찾아도 빈 거점이 된다.

## 6. 유닛 — 기체·파일럿·편대

### 6.1 편대

- 규모: 2기로 시작, 최대 4기 (거점·연구로 확장)
- 출격 단위이자 전투 중 교체 가능한 기체 풀

### 6.2 기체

| 항목 | 내용 |
|---|---|
| 역할 | 제공기 / 공격기 / 다용도기 / 폭격기 |
| 크기 | 소형 / 중형 / 대형. 활주로 길이로 운용 제한 |
| 티어 | 1~4티어. 정비소 등급으로 운용 제한 |
| 획득 | 상점 구매, 연구 해금 후 구매, 전리품·노획, 상부 보급 |
| 개조 | 부품 슬롯(엔진·장갑·전자장비 등) + 단계 강화. 3D 모델에 외형 반영 |
| 무장 | 하드포인트에 장착, 탄약은 출격마다 비용 소모 |
| 귀환 후 손상 | 유지되며 수리 비용·턴 소요 |
| 격추 | 아군 영역: 잔해 회수로 복구 가능 / 적 영역: 영구 손실 (개조·부품 포함) |

### 6.3 파일럿

| 구분 | 내용 |
|---|---|
| 네임드 에이스 | 이름 있는 개별 유닛. 스킬·성장·피로 보유. 소수 |
| 일반 파일럿 | 숙련도·피로만 가진 간단한 자원 |
| 기체와의 관계 | 자유 교체. 단, 파일럿마다 숙련 기종(적성)이 있어 맞는 기체에서 이득 |
| 에이스 획득 | 스토리 합류, 자금으로 고용, 일반 파일럿의 성장·승격, 적 에이스 포로 영입 |
| 비용 | 고용비 + 전원 턴당 급여 |
| 피로 | 출격 시 누적, 출격하지 않은 턴마다 기본 회복. 유흥가가 있는 거점에서는 회복 가속 |

### 6.4 격추와 탈출

- 기체가 격추되면 파일럿은 탈출한 것으로 처리 (영구 사망 없음)
- 가장 가까운 아군 거점까지의 거리에 따라 복귀 시간 발생
- 파일럿 능력치가 복귀 시간에 관여할 가능성은 열어둠
- 적 영역 상공에서 탈출하면 포로가 될 수 있음 → **구출 출격** 또는 **몸값 지불**로 해결
- 이 규칙은 적 파일럿에게도 대칭 적용 (적 에이스 포로·영입의 근거)

## 7. 출격 & 슈팅 전투

### 7.1 기본 규칙

| 항목 | 내용 |
|---|---|
| 스테이지 길이 | 미션 종류별 2~10분 (최대 10분) |
| 스크롤 | 강제 스크롤 + 플레이어 가감속 |
| 조작 대상 | 편대 내 기체 1기 (실시간 전환) |
| 기체 전환 | 전환 시 짧은 무방비/슬로우 발생 |
| 전경 기체 격추 | 다음 기체 자동 투입 (무방비 시간 포함) |
| 철수 | 구간 경계의 이탈 지점에서만 가능. 보스 직전에는 반드시 배치 |
| 결과 판정 | 목표 파괴율에 비례해 전략 맵에 효과 반영 |

### 7.2 비조작 기체 — 배경 레이어

- 조작하지 않는 기체는 횡스크롤 뒤쪽 레이어에서 연출용 가상 전투를 한다
- 실제 전투에 영향을 주지 않으며 피해도 입지 않는다
- 전투 종료 후, 전경에 나오지 않은 시간에 비례해 가벼운 손상을 입는다
- 경험치는 소량 획득

**설계 메모**: 한 번에 1기만 전경에 있으므로 편대 전체의 대기 시간 합은 (편대 기체 수 − 1) × 스테이지 시간으로 일정하다. 전환 방식은 경손상의 분배만 바꾸며, 편대를 크게 꾸릴수록 출격당 총 정비 부담이 커진다.

### 7.3 스테이지 구성

- **헥스 지형 × 미션 종류 × 적 단계**로 배경, 대공 배치, 적 구성이 결정된다
- 스토리·고유 거점 스테이지: 수작업 제작
- 일반 스테이지: 구간(청크) 모듈 조합 절차 생성
- 이탈 지점은 청크 사이 구간 경계에 배치

### 7.4 미션 종류

| 목적 | 미션 | 길이 | 보스 | 파괴율 → 전략 효과 |
|---|---|---|---|---|
| 적 부대 격파 | 부대 공격 | 4~6분 | 적 주력일 때만 | 적 부대 전력 감소 |
| 거점 공격 | 거점 폭격 | 6~10분 | 있음 | 대공·시설 파괴 → 아군 점령 성공률 상승, 일정 이상이면 등급 하락 |
| 아군 거점 방어 | 요격 | 4~6분 | 대규모 공세일 때만 | 격추율만큼 아군 거점 피해 감소 |
| 특수 | 정찰 | 2~3분 | 없음 | 진행 거리만큼 주변 적 부대 공개 (수 턴 유지) |
| 특수 | 호위 | 4~6분 | 없음 | 아군 수송기·폭격기·이동 중 지상군의 생존율만큼 보급·폭격·진격 효과 |
| 특수 | 보급선 차단 | 3~5분 | 없음 | 적 부대 보급 감소 (이동력·회복 저하) |
| 특수 | 구출 | 3~5분 | 없음 | 구출기 생존 시 포로 파일럿 귀환 |

- 주둔 편대의 **자동 요격**(적 턴, 해당 거점 피습 시 수치 정산)과 **요격 미션**(플레이어 출격)은 별개

## 8. 경제 & 성장

### 8.1 자원

자금 단일. 연료·탄약은 별도 자원이 아닌 출격 비용 항목.

### 8.2 수입

| 수입원 | 내용 |
|---|---|
| 상부 예산 | 턴당 지급, 신뢰도에 따라 증감 |
| 경제 시설 | 유흥가(주둔 파일럿 급여 환수), 정유·광산·금융 |
| 전과 보상 | 목표 파괴율 비례 + 특별 표적 현상금 (적 에이스·보스) |
| 점령 | 점령 보상, 전리품 (파괴된 시설 포함) |

### 8.3 지출

- 고정비 (매 턴): 영역 유지비, 파일럿 전원 급여, 지상군 유지비
- 성장: 영역 확장(누진), 시설 건설, 거점 등급·시설 등급 상승, 연구
- 전력: 기체·부품·무장 구매, 파일럿 고용비, 지상군 고용·훈련·장비 개선
- 출격: 편대 연료·탄약, 지상군 출동 비용(무장 비용)
- 손실: 수리, 몸값

**밸런싱 기준**: 고정비가 무거운 구조이므로 "몇 턴 연속 적자면 파산하는가"를 기준선으로 설정한다.

### 8.4 상점

- 상시 전 품목 구매 가능
- 실제 구매는 거점 등급(기체 티어)과 연구 해금으로 제한되며, 잠긴 품목은 사유를 표시

### 8.5 연구

| 항목 | 내용 |
|---|---|
| 구조 | 기술 트리 + 역설계 |
| 진행 재원 | 연구 포인트 + 자금 병행 |
| 연구 포인트 공급 | 연구소(4등급), 역설계, 전과 |
| 역설계 대상 | 노획 기체, 적 에이스 전용기, 점령 거점의 시설·장비 |
| 흐름 | 초반은 역설계·전과의 적은 포인트로 천천히 진행하며 상점·상부 보급으로 버틴다. 사령부 건설 후 본격 가속 (중반 전환점) |

### 8.6 상부 신뢰도와 지시 임무

| 항목 | 내용 |
|---|---|
| 지시 형태 | 상시 장기 목표 1개 + 전황 이벤트로 발생하는 긴급 지시 |
| 긴급 지시 기한 | N턴 이내, 초과 시 실패 처리 |
| 신뢰도 상승 | 지시 임무 성공, 영역·거점 확대 |
| 거부·실패 | 신뢰도 하락 + 예산 삭감 |
| 신뢰도 바닥 | 해임 (게임 오버) |

신뢰도는 전과와 손실 최소화를 반영하지 않는다. 상부는 명령 이행과 영토만 본다. 영역 확대는 신뢰도를 올리지만 유지비를 키운다.

## 9. 적 & 보스

| 항목 | 내용 |
|---|---|
| 세력 차별화 | 기체는 공유, 교리(전투 스타일)로 구분. 일부 에이스만 고유 기체 |
| 전략 AI | 세력별 성향 + 전황에 따른 태세 변경. 적 세력 간 교전 |
| 적 단계 | 적 부대·거점 전력 + 캠페인 진행 단계 |
| 보스 | 대형 지상 병기(요새·열차포·육상전함), 대형 항공기(거대 폭격기·공중항모), 해상 전력(항모·전함). 큰 목표에만 등장 |

### 9.1 라이벌 에이스

- 세력별 네임드 라이벌, 반복 등장하며 성장
- 전략 맵에 라이벌이 이끄는 부대가 표시되고, 해당 세력과 교전 시 확률로 스테이지에 난입
- 보스가 아닌 **스테이지 도중 난입 위협**으로 기능
- 격추 시 탈출 규칙 적용 → 복귀 후 재등장, 아군(플레이어) 영역 상공에서 탈출하면 포로·영입 가능

### 9.2 세력 교리 방향 (예시, 콘텐츠 단계에서 확정)

물량으로 밀어붙이는 세력, 대공망·요새화로 버티는 세력, 보급선을 노리는 세력, 약해진 쪽만 골라 치는 기회주의 세력.

## 11. UI/UX

### 11.1 전략 맵 (메인 허브)

- 2D 탑다운 헥스 맵이 항상 바탕, 나머지 화면은 패널로 열림
- 상단 바: 자금, 이번 턴 예상 수지(수입 − 유지비 − 급여), 상부 신뢰도, 턴
- 맵 표시: 영역 경계, 거점 등급, 편대 작전 반경, 탐지된 적 부대, 라이벌 부대

### 11.2 운영 패널

| 패널 | 기능 |
|---|---|
| 거점 관리 | 시설 건설, 영역 확장, 등급 상승 조건, 초토화 명령 |
| 격납고 | 편대 편성, 기체 손상·경손상, 부품 개조, 하드포인트 무장 |
| 파일럿 명부 | 숙련 기종, 피로(회복 예상 턴), 복귀 대기, 포로(구출/몸값) |
| 상점 | 구매, 잠금 사유 표시 |
| 연구 | 기술 트리, 역설계 대기 목록 |
| 지상군 | 고용·강화, 출동(목표 헥스 지정), 이동 중 부대 현황, 점령 후 주둔/복귀 배분 |
| 상부 통신 | 장기 목표, 긴급 지시와 남은 기한, 신뢰도 변동 내역 |

### 11.3 출격 흐름

1. **출격 계획**: 맵에서 편대별 목표 헥스 지정 (작전 지역 표시, 겹침 표시), 직접/자동 정산 선택, 출격 순서 정렬. 편대가 모두 빠지는 거점은 "방어 공백" 경고
2. **브리핑** (출격 1건마다): 미션 종류, 지형, 적 단계(앞 출격 결과 반영치), 보스 유무, 라이벌 출현 가능성, 예상 비용, 포로 위험 구역 여부
3. **편성 확인**: 편대 내 기체 순서
4. **전투 HUD** (직접 플레이): 편대 기체 아이콘(전환·무방비 표시), 파괴율 게이지, 다음 이탈 지점까지 거리, 라이벌 난입 경고
   **자동 정산**: 결과 요약 카드로 즉시 표시
5. **디브리핑**: 파괴율과 전략 효과, 보상, 손상·경손상, 격추·탈출·포로, 경험치, 역설계 획득물
6. 다음 순서 출격으로 → 모든 출격 종료 후 턴 종료 → 아군 지상군 AI → **적 턴 요약** (자동 요격, 거점 피해, 지상군 피습, 세력 간 교전)

### 11.4 조작

- 게임패드 기준: 숄더 버튼으로 패널 탭 전환, 스틱 커서 + 헥스 스냅 이동, 확인 동작 한 버튼 통일
- PC: 마우스로 헥스 직접 선택 병행
