## 1. 목적과 위치

### 1.1 검증 순서

| 순서 | 대상 | 상태 |
|---|---|---|
| 1차 | 횡스크롤 전투의 조작감 | 구현 완료, 피드백 수집 중 (~2026-10-20) |
| **2차 (본 문서)** | 전략 경제·다중 출격 턴 루프 | 자동 정산만으로 검증 (전투 완성 불필요) |
| 3차 | 블렌더 툰 스타일 기체 제작 품질·속도 | 병행 학습 |

### 1.2 프로토타입의 성격

- **버리는 코드**다. 기술 설계의 어셈블리 구조·DI·데이터 파이프라인·R3/MessagePipe를 따르지 않는다
- 단, 규칙은 Unity에 의존하지 않는 순수 C#(`Prototype.Strategy.Rules`, `noEngineReferences`)으로 분리한다. 화면 없이 N턴을 돌려 파산 기준·밸런스를 측정하기 위함이다
- 화면은 IMGUI 패널 + 병합 메시 헥스 맵. 아트는 단색 헥스와 기본 도형만
- 모든 무작위성은 규칙 쪽 시드 난수 하나로 처리 (기술 설계 2.6 원칙만 차용)
- 타임박스: **2026-09-30 ~ 2026-10-21 (3주)**. 기간이 끝나면 결과가 애매해도 판단을 내리고 종료한다
- 브랜치: `prototype/strategy` (`main`에서 분기, 전투 프로토타입과 섞지 않음)

## 3. 범위

### 3.1 포함

| 영역 | 내용 |
|---|---|
| 헥스 맵 | 1구역 약 16×12 헥스, pointy-top, 지형 5종(평지·산악·해상·해안·사막) + 유전 표식 |
| 세력 | 플레이어 + 적 세력 2개 (적끼리도 교전) + 중립 고유 거점 |
| 거점 | 아군 거점 2개로 시작. 영역 확장(누진 비용·유지비), 시설 건설, 거점 등급 1~4, 활주로 직선 요건, 전초기지 건설 |
| 경제 | 자금 단일. 상부 예산·경제 시설·전과 보상 / 영역 유지비·급여·지상군 유지비·출격 비용·수리. 상단 바에 예상 수지 |
| 편대 | 편대 2~3개, 편대당 2~4기. 기체 역할·크기·티어, 손상, 격납고 편성. 상점은 소수 품목만 |
| 파일럿 | 네임드 소수 + 일반. 숙련도·숙련 기종·피로, 탈출·복귀 시간·포로(구출·몸값 중 몸값만) |
| 출격 | 편대별 목표 헥스, 작전 지역(목표 + 인접 6), 1지역 1편대, 겹침 보정, 순서 지정, 순차 정산, 방어 공백 경고 |
| 자동 정산 | 추상 교전 라운드 리졸버 (기술 설계 5.4). 결과는 `SortieResult`와 같은 형태의 결과 카드 |
| 적 | 적 부대 이동·공격, 태세(확장·공세·방어·재정비) + 행동 점수화의 단순판, 편대 주둔 거점 자동 요격, 시야(탐지 범위) |
| 지상군 | 병영 고용, 출동(목표 헥스), 여러 턴 이동, 이동 중 피습, 점령 |
| 상부 | 신뢰도, 장기 목표 1개 + 긴급 지시(N턴 기한), 예산 증감, 해임 |
| 승패 | 승리: 목표 고유 거점 점령 / 패배: 해임, 전 거점 상실, 파산 |
| 측정 | 턴 로그(수지, 출격, 결과, 1턴 실소요 시간), 헤드리스 N턴 시뮬레이션, 디버그 튜닝 메뉴 |

### 3.2 제외

연구·역설계, 부품 개조, 라이벌 에이스, 초토화, 구역 개방·스토리, 직접 플레이 연동(전투 프로토타입과 연결하지 않음), 세이브·로드, 헥스 맵 에디터, 오버레이 셰이더, 로컬라이제이션.

직접 플레이 대비 불리폭(S7)은 리졸버 보정 계수를 조절 항목으로 두고, 전투 프로토타입 로그와 비교해 감으로 판단한다.

| 2 | 거점·영역·시설, 거점 등급, 활주로 직선 요건, 턴 수지와 파산 | S3, S4 |

| 4 | 출격 계획(작전 지역·겹침·순서), 자동 정산 리졸버, 디브리핑 카드, 격추 위치별 잔해 회수·포로 | S2, S5, S7 |
| 5 | 적 세력 AI(태세·행동), 적 턴 요약, 자동 요격, 방어 공백, 시야 | S1 |
| 6 | 지상군 출동·이동·점령, 상부 신뢰도·지시 임무, 승패 판정 | S1, S3 |
| 7 | 디버그 튜닝 메뉴, 턴 로그, 헤드리스 N턴 시뮬레이션, 테스터 빌드 | S8 |

범위가 3주에 비해 크므로, 일정이 밀리면 5·6단계에서 단순화할 항목을 먼저 정해 확인받는다.

## 5. 조작

| 입력 | 마우스·키보드 | 게임패드 |
|---|---|---|
| 헥스 선택 | 마우스 가리키기 + 왼쪽 클릭 | 왼쪽 스틱 커서(헥스 스냅) + South |
| 맵 이동 | WASD / 방향키 / 가운데 버튼 드래그 | 커서가 화면 가장자리에 닿으면 이동 |
| 확대·축소 | 휠 | RT / LT |
| 취소 | 오른쪽 클릭 / Esc | East |
| 디버그 메뉴 | F1 | View / Select |

패널 조작은 IMGUI라 마우스 전용. 게임패드 패널 조작(기획서 11.4)은 범위 밖.

## 7. 종료 조건과 결과 반영

- 타임박스 종료 시점 또는 S1~S8에 판단이 모두 나오면 종료
- 판단 결과는 기획서 12장 미정 사항(목표 턴 수, 등급 상승 조건, 시설 등급 수치, 자동 정산 공식, 파산 기준, 긴급 지시 기한)과 해당 절에 반영
- 프로토타입 코드는 폐기. 조절 항목의 최종 수치와 헤드리스 시뮬레이션 결과만 기록으로 남긴다
