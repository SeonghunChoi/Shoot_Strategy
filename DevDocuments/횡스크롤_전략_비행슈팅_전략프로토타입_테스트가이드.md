# 전략 프로토타입 테스트 가이드

> Shoot Strategy · 전략 턴 루프 프로토타입

턴제 헥스 전략 + 횡스크롤 비행 슈팅 게임의 **전략 부분**만 떼어 만든 시험판입니다. 전투는 모두 자동 정산(숫자 계산)으로 처리합니다. 그래픽은 색칠한 헥스뿐이고, 확인하고 싶은 것은 **"매 턴의 결정이 고민되고 재미있는가"**입니다.

- **기간**: 2026년 10월 21일까지
- **필요한 것**: 마우스·키보드 (패드도 되지만 패널 조작은 마우스가 편합니다)
- **한 판**: 30~60분. 끝까지 가지 않아도 됩니다

---

## 1. 시작 전에

- zip을 쓰기 가능한 폴더(바탕화면 등)에 풀고 `StrategyProto.exe`를 실행합니다. 설치·규칙·화면 설명은 함께 든 **`Manual.md`(사용 설명서)**에 있습니다.
- 실행하면 바로 1턴이 시작됩니다. **F1**로 조작 도움말, **F2**로 튜닝 메뉴를 엽니다.
- F2 메뉴 맨 위 **테스터 이름** 칸에 이름(닉네임)을 적어 주세요. 기록에 함께 남습니다.
- **R**로 언제든 처음부터 다시 시작합니다. 진행 중이던 판은 "중단"으로 기록됩니다.
- 기록은 자동으로 저장됩니다. 끝나면 [피드백 보내기](#7-피드백-보내기)의 폴더만 보내 주시면 됩니다.

## 2. 목표와 패배

| | 조건 |
|---|---|
| 승리 | **동부군 전진 기지 점령** (맵 가운데 동쪽, "★ 장기 목표") |
| 패배 | 상부 신뢰도 0 (해임) · 모든 거점 상실 · 자금 0 미만으로 3턴 연속 (파산) |

당신은 늘 돈이 모자란 전선 지휘관입니다. 매 턴 상부 예산이 들어오지만 영역 유지비·파일럿 급여·지상군 유지비가 빠져나갑니다. **쉬는 턴도 손해**입니다.

## 4. 화면과 한 턴의 흐름

**상단 바**: 자금 · 예상 수지(마우스를 올리면 항목별 내역) · 연속 적자 · **신뢰도**(누르면 상부 통신 창) · 턴 · 턴 종료

**오른쪽 패널 탭**

| 탭 | 하는 일 |
|---|---|
| 거점 | 영역 확장, 시설 건설·등급·철거, 거점 등급 상승, 전초기지 건설 |
| 격납고 | 편대 편성(기체 순서 ▲▼, 파일럿 배정), 재배치, 작전 반경 보기 |
| 출격 | 편대 → 목표 지정 → 순서 정리 → **출격 실행** → 디브리핑 |
| 지상군 | 병영에서 고용 → 출동(목표 클릭) → 적 거점 점령 |
| 상점 | 기체 구매·판매, 파일럿 고용 |
| 명부 | 파일럿 숙련·피로·포로(몸값) |

**턴 순서**: 내 턴(운영·재배치·출격) → 턴 종료 → 수지 정산 → 아군 지상군 이동 → **적 턴**(이동·공격·요격) → 다음 턴. 턴이 끝나면 **적 턴 요약** 창이 뜹니다.

## 5. 알아둘 규칙

- **시야**: 아군 영역에서 1칸 밖까지만 보입니다. 레이더를 지으면 그 거점 시야가 등급만큼 넓어집니다. 어두운 칸 = 시야 밖, 회색 = 마지막으로 본 위치.
- **출격**: 같은 목표에는 편대 하나. 목표가 다르면 작전 지역이 겹쳐도 되고, **먼저 친 출격이 뒤 출격을 쉽게** 만듭니다(대공 −30%). 출격한 편대는 그 턴 적이 와도 **요격하지 못합니다**.
- **작전 반경**: 편대 안에서 가장 짧은 기체 기준. **공중급유**(출격 탭)를 켜면 반경 2배, 비용 2배.
- **재배치**: 즉시 도착, 그 턴은 출격 불가. 적 턴에는 새 거점에서 요격합니다.
- **격추**: 아군·중립 상공이면 잔해 회수(수리 필요). **적 영역이면 기체 영구 손실 + 파일럿 포로 가능**.
- **손상·피로**: 정비소가 있는 거점에서 빨리 수리됩니다. 피로 70 이상은 출격 불가. 유흥가가 피로 회복을 돕습니다.
- **거점 피습**: 적 부대가 인접하면 공격합니다. 주둔 편대 요격 → 대공포·SAM → 주둔 지상군 순으로 막고, 남은 적 전력이 10 이상이면 거점을 빼앗깁니다.
- **적은 보이는 것만 압니다**: 적 부대에서 3칸 안의 거점만 편대 수를 압니다. 편대를 비워도 적이 모르면 안 옵니다.
- **전초기지**: 아군 거점에서 3칸 이상 떨어진 곳, 편대(급유 포함)나 지상군이 닿는 칸에 지을 수 있습니다.
- **점령**: 지상군이 적 거점 인접에서 전력 > 대공 + 시설이면 점령. 먼저 폭격으로 시설을 깎아 두세요.
- **상부**: 신뢰도에 따라 예산이 달라집니다(신뢰도 50 → 400, 100 → 600). 5턴마다 긴급 지시가 오고, 완수 +10, 실패 −15, 거부 −10입니다.

## 5-1. 버전 비교 (두 빌드를 받은 경우)

이 빌드는 **비행판 (C)**입니다 (화면 오른쪽 위에 표시). 함께 받은 **체공판 (A+B)**과 번갈아 해 보고 비교해 주세요. 규칙은 같고 **편대가 움직이는 방식만** 다릅니다.

| 버전 | 편대 |
|---|---|
| 체공판 (A+B) | 출격은 한 턴 안에 왕복. 연료가 남으면 [체공]으로 적 턴 동안 목표 상공에 남아 감시·요격 |
| 비행판 (C) | 출격하면 맵 위를 여러 턴 날아다님. 턴마다 속도만큼 이동, 연료가 떨어지기 전에 아군 거점에 착륙 |

| # | 질문 |
|---|---|
| V1 | 어느 쪽이 "내 편대가 전장에 있다"는 느낌이 강했나요? |
| V2 | 어느 쪽의 결정이 더 재미있었나요? 어느 쪽이 더 귀찮았나요? |
| V3 | 한 턴에 걸린 시간이 어느 쪽이 길었나요? 그게 괜찮았나요? |
| V4 | 하나만 남긴다면 어느 쪽? 이유는? |

## 6. 질문 S1–S8

정답은 없습니다. 느낀 그대로, 특히 **"어느 순간에 그랬는지"**를 적어 주세요.

| # | 질문 | 해 볼 것 |
|---|---|---|
| S1 | "어디를 칠까 / 어디를 비워 둘까"가 매 턴 실제로 고민됐나요? | 편대를 모두 출격시켜 보고, 그 턴에 거점이 공격받는 경험 |
| S2 | 출격 순서를 바꾸면 결과가 달라진다는 게 느껴졌나요? | 동부군 경비대 → 전진 기지 순서와 그 반대 |
| S3 | 돈이 모자란 압박이 긴장감이었나요, 그냥 괴로웠나요? | 수입 시설 없이 버텨 보기, 예상 수지 툴팁 보기 |
| S4 | "칸 하나에 시설 하나", 활주로 직선 요건이 의미 있는 고민이었나요? | 거점 등급을 올리며 시설 배치 |
| S5 | 적 영역 상공 격추(영구 손실·포로)가 목표 선택을 바꿨나요? | 적 거점 폭격, 포로 몸값 |
| S6 | 손상·피로 관리(로테이션)가 재미였나요, 잡일이었나요? | 같은 편대를 연속 출격시켜 보기 |
| S7 | 디브리핑(자동 정산 결과)을 읽고 납득됐나요? | 라운드 기록 읽기, 기체 순서 바꿔 다시 출격 |
| S8 | 한 턴에 대략 몇 분 걸렸나요? 너무 길거나 짧았나요? | (시간은 자동 기록됩니다. 체감만 알려 주세요) |

## 7. 피드백 보내기

1. **기록 폴더**: F2 메뉴의 **로그 폴더 열기** → `PlaytestLogs/strategy` 폴더 전체. `runs.csv`(판), `turns.csv`(턴마다 자금·수지·실제 걸린 시간), `events.csv`(출격·피습·점령·지시), 내보낸 `tuning_….md`가 들어 있습니다. 개인 정보는 없고, 입력한 테스터 이름만 남습니다.
2. **답변**: 아래 양식을 복사해 채워 주세요.

```text
테스터 이름:
전략 게임 경험: (많음 / 조금 / 거의 없음)
결과: (승리 / 해임 / 거점 상실 / 파산 / 중간에 그만둠) · 몇 턴까지:

S1 방어 공백 고민:
S2 출격 순서:
S3 돈 압박:
S4 시설 배치:
S5 적 영역 격추·포로:
S6 손상·피로 관리:
S7 디브리핑 납득:
S8 한 턴 체감 시간:

V1 편대 존재감 (체공판 / 비행판):
V2 더 재미있던 쪽 / 더 귀찮던 쪽:
V3 한 턴 시간:
V4 하나만 남긴다면:

가장 재미있었던 결정:
가장 귀찮았던 조작:
그 밖에 하고 싶은 말:
```
