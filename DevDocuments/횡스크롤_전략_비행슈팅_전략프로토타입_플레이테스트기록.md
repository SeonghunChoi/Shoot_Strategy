## 2. 구현 메모

| 항목 | 결정 | 이유 |
|---|---|---|
| 헥스 좌표 | pointy-top, 축 좌표 저장, 맵은 odd-r 오프셋 사각형 | 기술 설계 4.1 |
| 지형 열거형 이름 | `TerrainType` | `UnityEngine.Terrain`과 이름 충돌, 기술 설계 5.1 출격 계약의 이름과 맞춤 |
| 규칙 어셈블리 | `Prototype.Strategy.Rules` (`noEngineReferences`) | 헤드리스 N턴 시뮬레이션 (7단계) |
| 난수 | SplitMix64, 상태 `ulong` 하나 | 기술 설계 2.6. 상태를 기록·복원해 재현 |
| 맵 렌더 | 정점 색 병합 메시 + 커스텀 무조명 셰이더(Resources) | 헥스별 오브젝트 없음 (기술 설계 4.4). Linear 색 공간이라 정점 색을 변환해 넣음 |
| IMGUI 버튼 동작 | 버튼을 누른 이벤트에서 바로 실행하지 않고 다음 Layout 이벤트에서 실행. 조건부 UI(툴팁 등)의 표시 판정도 Layout에서만 | 같은 프레임의 Layout·Repaint 사이에 컨트롤 수가 달라지면 IMGUI가 예외를 던짐 |
| 패드 패널 조작 | 방향키 위·아래로 오른쪽 패널 버튼 초점, South 실행, East 해제. 끝에서 멈춤(순환 없음). 초점 버튼이 보이도록 자동 스크롤 | 검증계획 5장에서는 범위 밖이었으나 패드만으로 테스트가 불가능해 2단계에서 추가 |
| 파산 | 자금 0 미만으로 마친 턴 3회 연속 | 2단계 확인 사항. 예상 수지가 음수인 것만으로는 파산하지 않음 |
| 거점 본부 칸 | 시설 불가, 상한과 별개 | 2단계 확인 사항 |
| 해상 칸 | 영역 확장은 가능, 시설·전초기지 불가 | 시야·대공 범위용 (5단계) |

## 3. 세션 로그

### 2026-10-01 — 1단계 (헥스 맵 기반)

- 구현: 1구역 16×12 맵(지형 5종 + 유전 표식), 카메라 이동·확대, 마우스·패드 커서, 칸 선택, 선택 칸→커서 칸 직선 표시(직선 방향이면 노랑), 상단 바 틀, 조작 도움말
- 검증: EditMode 테스트 16개 통과 (거리·인접·범위·링·직선·직선 방향·오프셋 왕복·반올림·맵 파싱·난수 재현). Windows 빌드 자동 스크린샷에서 렌더·한글 UI 확인
- 사용자 확인: 에디터에서 동작 확인 완료

### 2026-10-01 — 2단계 (거점·영역·시설·턴 수지)

- 구현: 시작 거점 2개(해안 기지 2등급, 남부 전초기지 1등급), 영역 확장(누진 비용), 시설 13종 건설·등급·철거, 거점 등급 1~4(상한·필요 시설), 활주로 직선 길이 → 운용 기체 크기, 전초기지 건설, 턴 수지(상부 예산 300, 유지비 10/칸, 정유·광산·금융 수입), 연속 적자 파산, 턴 정산 로그, 게임 오버 창
- 검증: EditMode 테스트 28개 통과 (.NET으로 별도 실행 — Unity 에디터가 프로젝트를 열고 있어 배치 모드 사용 불가). 화면 코드는 Unity DLL 참조로 별도 컴파일, 오류·경고 0
- 사용자 확인 중 발견·수정
  - 패드로 패널 메뉴를 실행할 방법이 없음 → 방향키 초점 조작 추가
  - 초점 버튼이 패널 아래로 벗어나면 스크롤이 따라가지 않음 → 자동 스크롤
  - 예상 수지 툴팁에서 `ArgumentException: Getting control 3's position…` → 툴팁 표시 판정을 Layout에서만
  - 방향키로 초점을 옮기면 보이지 않는 항목을 돌다가 나타남 → 버튼 목록을 Layout에서만 채우도록 (이벤트마다 중복 등록되던 문제). 끝에서 순환하지 않고 멈추도록 변경
  - 자금 부족인데 영역 확장 버튼이 활성 → 자금 부족·넓힐 칸 없음이면 비활성
- 현재 상태로는 지출이 영역 유지비뿐이라 자금 압박(S3)은 판단 불가. 3단계 급여 이후 판단
