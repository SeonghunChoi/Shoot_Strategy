# 전투 프로토타입 테스트 가이드

> Shoot Strategy · 전투 프로토타입

턴제 전략 + 횡스크롤 비행 슈팅 게임의 전투 부분만 떼어 만든 시험판입니다. 그래픽은 모두 임시 도형이고, 확인하고 싶은 것은 오직 **조작감**입니다. 한 판에 3~4분, 전체 30~40분 정도 걸립니다.

- **대상**: 테스트에 참여해 주신 분
- **기간**: 2026년 10월 20일까지
- **필요한 것**: 키보드, 가능하면 게임패드

## 1. 시작 전에

> **⚠ 첫 판은 이 가이드를 읽지 말고 플레이해 주세요.**
> 실행하자마자 3분 정도, 설명 없이 조작을 알아내 보는 과정 자체가 가장 중요한 관찰 자료입니다(Q1, Q8). 헷갈렸던 점, 처음 눌러 본 키를 기억해 두었다가 알려 주세요. 그다음에 이 가이드를 보면서 나머지 테스트를 진행하면 됩니다.

- 전달받은 빌드 폴더의 실행 파일(`ShootStrategyCombat.exe`)을 켜면 바로 전투가 시작됩니다. 메뉴 화면은 없습니다.
- `R` (패드 `Start`)를 누르면 언제든 처음부터 다시 시작합니다.
- `F1` (패드 `View` / `Select`)로 디버그 메뉴를 엽니다. 메뉴는 **마우스로만** 조작됩니다.
- 먼저 디버그 메뉴 맨 위 **테스터 이름** 칸에 이름(닉네임)을 적어 주세요. 기록에 함께 남습니다.
- 기록은 자동으로 저장됩니다. 끝나면 [피드백 보내기](#8-피드백-보내기)의 파일만 보내 주시면 됩니다.

> 💡 빌드판에서는 디버그 메뉴로 바꾼 설정이 게임을 끄면 초기화됩니다. 설정을 바꿔 가며 테스트했다면 끄기 전에 **튜닝 값 내보내기**를 눌러 주세요.

## 2. 조작

게임패드는 버튼 배치가 세 가지 있고 디버그 메뉴의 **입력 · 선회 ▸ 패드 입력 배치**에서 바꿉니다. 어느 배치가 편한지가 테스트 질문 중 하나입니다(Q8). 키보드는 배치와 관계없이 같습니다.

| 동작 | 키보드 | 패드 배치 1 | 패드 배치 2 | 패드 배치 3 |
|---|---|---|---|---|
| 위아래 이동 | `W` `S` / `↑` `↓` | 왼쪽 스틱 | 왼쪽 스틱 | 왼쪽 스틱 |
| 가로 입력 (가속·감속) | `A` `D` / `←` `→` | 왼쪽 스틱 좌우 | 왼쪽 스틱 좌우 | `RT` 가속 · `LT` 감속 |
| 기관포 | `J` | `RT` | `RT` | `A` / `✕` |
| 하드포인트 무장 | `K` | `LT` | `LT` | `B` / `○` |
| 무장 바꾸기 (미사일 ↔ 폭탄) | `Q` / `E` | 방향키 좌우 | 방향키 좌우 | `X` / `□`, `Y` / `△` |
| 기체 전환: 짧게 누르기 | `L` | `LB` | `Y` / `△` | `LB` |

## 4. 알아둘 규칙

### 화면이 흐르는 방식

기체는 화면 가로 위치에 고정되어 있고, 좌우 입력은 기체를 옮기는 대신 **배경이 흐르는 속도**를 바꿉니다. 방식은 세 가지이고 디버그 메뉴 **가로 입력 ▸ 가로 입력 모드**에서 고릅니다.

| 모드 | 동작 |
|---|---|
| A: 위치 오프셋 | 기본 속도로 흐르고, 좌우 입력은 정해진 범위 안에서 앞뒤로 밀어내는 효과. 손을 떼면 그 자리에 머묾 |
| B: 속도 조절 | 좌우 입력으로 가속·감속. 손을 떼면 그 속도를 유지 (스로틀처럼) |
| B + 순항 복귀 | B와 같지만 손을 떼면 기본 속도로 천천히 돌아옴 |

적과 적의 탄, 폭탄은 모두 땅을 기준으로 움직입니다. 가속하면 적이 더 빨리 다가오고, 폭탄은 떨어뜨린 순간의 속도를 이어받습니다. 적은 내 기체가 갈 곳을 예측해 쏘기 때문에, 발사 직후 속도나 높이를 바꾸면 피할 수 있습니다.

### 편대와 기체 전환

| | 제공기 | 공격기 | 폭격기 |
|---|---|---|---|
| 체력 | 80 | 100 | 140 |
| 위아래 이동 | 빠름 | 보통 | 느림 |
| 가로 입력 폭 | 넓음 | 보통 | 좁음 |
| 기관포 | 빠르고 강함 | 보통 | 느리고 약함 |
| 하드포인트 | 미사일 8 | 미사일 4, 폭탄 8 | 대형 폭탄 6 |

- 전환 버튼을 **짧게** 누르면 다음 기체, **길게** 누르면 기체 주위에 3칸 링이 열립니다. 방향으로 고르고 버튼을 떼면 확정, 가운데에서 떼면 취소입니다. 링이 열린 동안은 게임이 느려집니다(설정에서 끌 수 있음).
- 교대 직후 잠깐(**무방비 시간**)은 쏠 수 없고 위아래 움직임이 느려집니다. 이때 맞으면 피해를 그대로 받습니다.
- 체력과 잔탄은 기체마다 따로입니다. 뒤로 빠진 기체는 회복되지 않습니다.
- 조종 중인 기체가 격추되면 다음 기체가 자동으로 들어옵니다. 3기 모두 격추되면 편대 전멸이고, 테스트 편의상 2초 뒤 편대가 복구됩니다.

### 스테이지

- **평지**(약 700m) → **산악**(약 900m, 봉우리와 천장 돌출부) → **선회 구역**(160m, 보스) 순서입니다.
- 지형에 부딪히면 피해를 입고 튕겨 나옵니다. 정면으로 박으면 뒤로도 밀립니다.
- 선회 구역 가운데에 지상 요새 보스가 있습니다. 구역 끝에 닿으면 자동으로 방향을 바꿔(선회) 되돌아옵니다. 선회하는 동안은 조작할 수 없고 무적입니다.
- 보스는 **포탑 2개를 먼저** 부숴야 가운데 코어가 열립니다(회색 → 빨강). 코어를 부순 뒤 오른쪽 끝으로 나가면 스테이지 종료입니다.

## 5. 디버그 메뉴

`F1` / `View`로 열고 닫습니다. 창은 제목 줄을 끌어 옮길 수 있고, 반투명이라 뒤의 게임이 보입니다. 슬라이더는 마우스로 끌면 바로 적용됩니다. 테스터 이름 칸에 글자를 입력하는 동안에는 `R`가 리셋으로 동작하지 않습니다.

### 맨 위 버튼

| 버튼 | 설명 |
|---|---|
| 리셋 | 처음부터 다시 시작 (`R`와 같음) |
| 튜닝 값 내보내기 | 지금의 설정 전체를 파일로 저장. 설정을 바꿔서 테스트했다면 꼭 눌러 주세요 |

| 입력 상태 | 지금 인식된 장치, 스틱 값, 눌린 버튼. 패드가 안 먹힐 때 여기서 확인 |

테스트에서 주로 바꿀 항목만 적었습니다. 나머지는 그대로 두셔도 됩니다. 맨 아래 **기본값으로 초기화**로 언제든 되돌릴 수 있습니다.

| 구분 | 항목 | 설명 |
|---|---|---|
| 플레이테스트 | 테스터 이름 | 기록에 남는 이름 |
| 가로 입력 | 가로 입력 모드 | A / B / B + 순항 복귀 (Q1, Q2) |

| 가로 입력 | A: 오프셋 범위 / 이동 속도 | 모드 A에서 앞뒤로 밀 수 있는 폭과 빠르기 |
| 가로 입력 | B: 감속 폭 / 가속 폭 / 가속도 | 모드 B에서 기본 속도보다 얼마나 느리게·빠르게 갈 수 있는지 |

| 지형 충돌 | 피해 / 튕김 강도 | 산악에서 부딪혔을 때의 벌칙 크기 (Q9) |

| 스테이지 | 스테이지 사용 / 등장 간격 배율 | 끄면 평지에서 적이 끝없이 나옴. 바꾼 뒤 리셋해야 적용 |

> 💡 맵 높이, 스테이지 사용 여부처럼 지형에 관한 설정은 바꾼 뒤 `R`로 리셋해야 반영됩니다.

## 6. 테스트 순서

아래 순서대로 한 번씩 해 보시면 모든 질문을 한 번은 겪게 됩니다. 각 판이 끝나면 떠오른 느낌을 바로 메모해 두세요. 한 줄이어도 충분합니다.

1. **설명 없이 한 판** `Q1` `Q8`
   가이드를 보기 전에 실행해서 조작을 스스로 찾아보기. 무엇이 헷갈렸는지 기억해 두기.
2. **가로 입력 모드 비교** `Q1` `Q2`
   A, B, B + 순항 복귀로 각각 한 판씩. 가능하면 스틱과 패드 배치 3(트리거)으로도 모드 B를 해 보기.
3. **입력 배치 비교** `Q8`
   패드 배치 1, 2, 3과 키보드로 평지 구간만 짧게. 특히 기체 전환 버튼을 자주 눌러 보기.
4. **기체 전환 집중** `Q4` `Q5`
   무방비 시간 0 / 0.5 / 1초, 링 슬로모션 켜기·끄기를 바꿔 가며. 짧게 누르기와 링 메뉴를 둘 다 써 보기.
5. **산악과 레이더** `Q3` `Q9`
   산악 구간을 레이더 방식별로 비행. 지형 충돌 피해·튕김을 한 번쯤 바꿔 보기. 카메라 추적 방식도 바꿔 보기.
6. **보스까지 완주** `Q6`
   편한 설정으로 보스를 격파하고 결과 창까지.
7. **임의 선회** `Q7`
   "임의 선회 허용"을 켜고 평지·산악·보스에서 자유롭게 방향을 바꿔 보기.

## 7. 질문 Q1–Q9

이 테스트로 답을 얻고 싶은 질문들입니다. 정답은 없고, 느낀 그대로가 가장 좋은 답입니다. "별로였다"면 어느 순간에 그랬는지가 특히 도움이 됩니다.

### Q1. 좌우 입력이 "속도감"으로 느껴지나요?

보통 횡스크롤 슈팅은 좌우 입력으로 기체가 화면 안에서 움직이지만, 이 게임은 기체가 제자리에 있고 배경이 빨라지거나 느려집니다.

- **해 볼 것**: 세 가지 모드를 모두. 처음 할 때 좌우를 눌렀을 때의 첫인상.
- **알려 줄 것**: 직관적이었는지, 기체가 안 움직여 답답했는지, 익숙해지는 데 얼마나 걸렸는지.

### Q2. 모드 A와 모드 B 중 어느 쪽이 더 재미있나요?

A는 화면 안에서 앞뒤로 위치를 조정하는 느낌, B는 비행기의 스로틀처럼 속도를 조절하는 느낌입니다. B + 순항 복귀는 그 중간입니다.

- **해 볼 것**: 같은 구간을 A, B, B+로. 모드 B는 스틱과 트리거(배치 3) 양쪽으로.
- **알려 줄 것**: 가장 좋았던 모드와 이유. 입력 장치에 따라 답이 달라졌는지.

### Q3. 위아래로 넓은 맵에서 적 위치를 잘 파악할 수 있나요?

맵이 화면보다 2.5배 높아서 화면 밖 위아래에도 적이 있습니다. 카메라가 기체를 따라가고, 레이더가 화면 밖 적을 알려 줍니다.

- **해 볼 것**: 레이더 가장자리 / 세로 띠 / 둘 다 / 끄기. 카메라 즉시 / 부드럽게 / 데드존.
- **알려 줄 것**: 화면 밖에서 갑자기 나타난 적에게 당한 적이 있는지, 어떤 레이더가 도움이 됐는지, 카메라가 어지러웠는지.

### Q4. 전투 중 기체 전환이 부담 없이 손에 붙나요?

교대 직후의 무방비 시간은 일부러 넣은 대가입니다. 긴장감을 주는지, 그냥 불쾌한지가 궁금합니다.

- **해 볼 것**: 무방비 시간 0 / 0.5 / 1초. 위험한 순간에 기체를 바꿔 보기.
- **알려 줄 것**: 전환을 자주 하게 됐는지 피하게 됐는지, 무방비 시간이 적당했는지, 무방비 중에 맞았을 때의 기분.

### Q5. 짧게 누르기만으로 충분한가요? 링 메뉴에 슬로모션이 필요한가요?

짧게 누르면 순서대로 다음 기체, 길게 누르면 링에서 원하는 기체를 고릅니다.

- **해 볼 것**: 두 방식을 모두. 링 슬로모션 켜기·끄기.
- **알려 줄 것**: 주로 어느 쪽을 썼는지, 링을 열었다가 그냥 닫은 적이 있는지, 슬로모션이 없으면 링을 쓰기 어려웠는지.

### Q6. 선회 구역의 보스전이 한 방향 진행과 다른 재미를 주나요?

보스는 움직이지 않는 지상 요새라, 구역을 오가며 여러 번 지나가면서 부위를 부숩니다. 끝에 닿으면 자동으로 선회합니다.

- **해 볼 것**: 보스 격파까지 완주.
- **알려 줄 것**: 오가는 공략이 재미있었는지 지루했는지, 자동 선회가 자연스러웠는지, 선회 시간이 길거나 짧게 느껴졌는지.

### Q7. 아무 때나 선회할 수 있으면 더 재미있나요?

"임의 선회 허용"을 켜면 선회 구역이 아니어도 방향을 바꿀 수 있습니다. 재미가 늘 수도, 게임의 성격이 흐려질 수도 있습니다.

- **해 볼 것**: 평지·산악·보스에서 자유롭게 선회.
- **알려 줄 것**: 자주 쓰게 됐는지, 어떤 상황에서 썼는지, 켜 두는 쪽과 끄는 쪽 중 어느 게 좋은지.

### Q8. 버튼 배치가 진입장벽 없이 익혀지나요? 키보드로도 할 만한가요?

트리거 2개와 숄더 버튼 중심의 배치입니다. 배치 3은 트리거로 가감속하고 기관포를 A 버튼으로 옮긴 안입니다.

- **해 볼 것**: 패드 배치 1, 2, 3과 키보드.
- **알려 줄 것**: 가장 편했던 배치, 손가락이 꼬이거나 헷갈린 버튼, 키보드로 끝까지 할 수 있을지.

### Q9. 지형에 부딪히는 것이 적당한 긴장감을 주나요?

산악 구간에서 지형에 부딪히면 피해를 입고 튕겨 나옵니다.

- **해 볼 것**: 산악 구간 통과. 가능하면 지형 충돌 피해·튕김 강도를 한 번 바꿔서.
- **알려 줄 것**: 통로가 너무 좁거나 억울했던 곳, 튕김이 과하거나 약했는지, 속도를 줄이며 조심해서 지나가게 됐는지.
